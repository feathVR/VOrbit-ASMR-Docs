# 常见疑问

## 购买前可以了解操作方法吗？

可以。本使用指南公开提供，购买前就能了解所需的应用、连接方式和设置流程。

## 一开始需要设置左右、上下、深度全部三个轴吗？

不需要。建议先只用左右轴确认动作。上下和深度请在追踪输入源能提供稳定数值时再添加。

## 未分配的轴会怎样？

选择 `—` 的轴视为位于中心。即使留有以前的校准值，也不会影响该轴的位置。

## 在哪里可以找到 Stream Deck 插件？

Stream Deck 插件随应用提供。安装后把操作放到按键上。参阅 [Stream Deck 与外部控制](features/other#stream-deck)。

## 如何报告问题？

关于本指南内容的问题，可以在本站的 GitHub 仓库中报告。关于产品本体的支持窗口，请查看发布时的说明。
