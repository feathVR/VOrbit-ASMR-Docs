# 常见问题

应用内“使用方法”标签的“无法正常工作时”中也有同样的检查步骤。

![“使用方法”界面](/img/screenshots/zh-Hans/help-zh-Hans.png)

_“使用方法”标签。可以重新开始教程、打开本指南，并查看按目的分类的步骤。确认双耳效果时请使用耳机。_

## 出现噼啪声或掉音

1. 在“设备”中确认麦克风和输出的采样率。
2. 把两者设为相同的采样率（支持：44100 / 48000 / 88200 / 96000 Hz）。采样率可在 Windows 的声音设置或音频接口的设置界面中更改。
3. 先按“停止”，再重新按“开始”。
4. 仍然持续时，请开启“防掉音模式”（延迟增加约 30 ms）。

使用音频接口时，[DAW（VST 桥接）](../audio/vst-bridge)可能更稳定。

## 听不到自己的声音・没有声音

- 确认顶部按钮显示为“停止”（正在运行）。
- 依次查看输入电平表和输出电平表。只有输入在动时，请检查输出设备和“声音”标签的输出音量。
- 确认输入和输出设备是你想用的设备。重新连接设备后，请按“重新检测”。
- 确认顶部的“静音”没有开启，也检查 Windows 一侧的静音和音量。
- 音频路径为“DAW（VST 桥接）”时，请检查 DAW 的输入输出和监听。

## 无法连接追踪・点不变成蓝色

- 确认“位置”标签的操作模式为“自动追踪”。
- 确认输入源显示为“接收中”。
- 确认使用的轴分配了 `—` 以外的参数。
- 确认已分配的轴显示为“已校准”。

## 声音会动，但位置不自然

- 用虚拟形象平常的姿势重新[校准](../tracking/calibration)。
- 检查“移动范围”中的“反转”和“平滑”。
- 确认“围绕头部转动（推荐）”的开关符合你的意图。
- 检查“左右环绕”“上下环绕”“深度变化幅度”。

## 同一台电脑上的其他应用收不到 VMC 了

请在“连接的详细设置”中启用“转发收到的数据（端口）”。详情请参阅[追踪输入源](../tracking/overview#vmc-forwarding)。

## 联动无法连接

确认双方都已按“开始”，然后用新的邀请码从头再试。也可以试试其他固定宽带或支持 IPv6 的网络。详情请参阅[联动通话](../collab/call#cannot-connect)。

## 声音重复・有回声

- 确认 OBS 没有从两个通道采集同一声音（[把声音送进 OBS 和直播](../streaming/obs)）。
- 确认扬声器的声音没有回到麦克风。建议使用耳机。

## 仍无法解决时

在“关于”标签中按“导出诊断 ZIP”，确认内容后附在问题报告中。诊断 ZIP 不包含音频、邀请码或认证信息。
