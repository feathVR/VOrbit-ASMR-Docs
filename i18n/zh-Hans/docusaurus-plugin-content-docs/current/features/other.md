# 音源・快捷键・精简视图

## 音源（播放音频文件）

在“音源”标签中，可以分别播放 4 个音频文件。可以把音效和环境音与声音一起放进空间中。

![“音源”界面](/img/screenshots/zh-Hans/playback-zh-Hans.png)

_“音源”界面。4 个栏位各读取一个音频文件。_

- 按各栏位的“选择文件”，或把音频文件拖放到栏位上即可读取。
- 支持 WAV / MP3 / M4A / AAC / FLAC / WMA（Windows 支持的编解码器），每个文件最长 10 分钟。
- **单声道**音源可以移动位置。它在“位置”标签的面板上显示为带编号的圆，随时可以拖动。
- **立体声**音源会保持原有的左右声场播放，无法移动位置。
- 播放前需要先按顶部的“开始”运行音频处理。
- 播放的声音会混入与麦克风相同的输出，联动通话中也会发送给对方。音量在各栏位中调整。
- 点击或拖动波形可以选择播放位置。

## 快捷键

在“快捷键”标签中，可以给应用的操作分配键盘快捷键。操作其他应用时也有效。

![“快捷键”界面](/img/screenshots/zh-Hans/hotkeys-zh-Hans.png)

_“快捷键”界面。为每个操作分配按键。_

1. 勾选“启用快捷键”。
2. 按要分配的操作所在行右侧的按键栏。
3. 按下想用的按键再松开（也可与 Ctrl・Alt・Shift 组合）。

按 Esc 取消，按 × 解除分配。Windows 键、Esc、F12 等保留键无法使用。与其他应用冲突而无法注册时，请换一个按键，然后按“重新检查冲突”。

## 精简视图与窗口置顶

按顶部的“精简视图”，会切换成直播时不占地方的小窗口。在小窗口中也可以进行开始、静音、播放音源和联动通话等操作。按“返回完整视图”恢复原样。

勾选“窗口置顶”后，VOrbit ASMR 的窗口会始终显示在其他窗口前面。
