# 音源・快捷键・精简视图

## 音源（播放音频文件）

在“音源”标签中，可以分别播放 4 个音频文件。可以把音效和环境音与声音一起放进空间中。

![“音源”界面](/img/screenshots/zh-Hans/playback-zh-Hans.png)

_当前应用画面。可用功能取决于发行版本。_

- 按各栏位的“选择文件”，或把音频文件拖放到栏位上即可读取。
- 支持 WAV / MP3 / M4A / AAC / FLAC / WMA（Windows 支持的编解码器），每个文件最长 10 分钟。
- **单声道**音源可以移动位置。它在“位置”标签的面板上显示为带编号的圆，随时可以拖动。
- **立体声**音源会保持原有的左右声场播放，无法移动位置。
- 播放前需要先按顶部的“开始”运行音频处理。
- 播放的声音会混入与麦克风相同的输出，联动通话中也会发送给对方。音量在各栏位中调整。
- 点击或拖动波形可以选择播放位置。

## 播放、暂停和音量 {#playback-controls}

播放时按钮变为“暂停”。暂停保留位置，再次播放从该处继续。“停止”返回开头。点击波形或拖动后松开，播放时会跳转，停止或暂停时只选择下次播放位置。立体声波形上方为左 L，下方为右 R。高度按文件内最大峰值缩放，并不表示输出音量。

音量以 dB 调整（−60 到 +20 dB；0 dB 为原始音量，−60 dB 为静音）。每个音源的“混响”决定是否添加房间混响。单声音源也可在音源页面的正面和俯视面板中拖动。这些面板不显示你的人声，显示范围与位置页面分别保存。

## 预设和音源组合 {#source-sets}

从“预设”选择随附的声音。Mosco 的《VR向けASMRループ音源集》第 1–3 集仅供在应用内播放，不能提取作其他用途。关于页面提供作者信息和素材集链接。未包含预设包的版本不显示此菜单。

“音源组合”一起保存音源 1–4 的声音、音量、循环、位置和混响设置。

1. 停止所有正在播放的音源，在“读取组合”中选择随附或已注册的组合。“从文件读取…”也可打开 .vorbitset 文件。
2. 调整后使用“保存组合”。保存的组合也会注册供 Stream Deck 使用。
3. “注册现有组合…”注册已有组合。“取消注册”只移除注册，不删除原组合和音频文件。

音源播放时不能加载组合。音频文件不会复制进组合，移动或删除后可能无法使用。

## 快捷键

在“快捷键”标签中，可以给应用的操作分配键盘快捷键。操作其他应用时也有效。

![“快捷键”界面](/img/screenshots/zh-Hans/hotkeys-zh-Hans.png)

_当前应用画面。可用功能取决于发行版本。_

1. 勾选“启用快捷键”。
2. 按要分配的操作所在行右侧的按键栏。
3. 按下想用的按键再松开（也可与 Ctrl・Alt・Shift 组合）。

按 Esc 取消，按 × 解除分配。Windows 键、Esc、F12 等保留键无法使用。与其他应用冲突而无法注册时，请换一个按键，然后按“重新检查冲突”。

## 全部静音 {#master-mute}

顶部扬声器按钮停止人声、音源、混响、对方声音以及向对方发送的声音。按钮变红，窗口标题显示静音状态。再次按下恢复。文件仍在无声播放。这与只关闭通话麦克风不同。启动时会解除静音。

咳嗽等情况下，可给快捷键或 Stream Deck 分配按住时静音，也可分配捂耳操作。长按普通快捷键不会重复操作。设置期间快捷键暂停，取消或冲突会保留原分配。

## Stream Deck 与外部控制 {#stream-deck}

安装随附的 Stream Deck 插件，将操作放到按键上，可控制全部静音、捂耳、音源播放及音量、加载音源组合等。应用运行时自动连接。红色连接图标表示未连接，断开时按下的操作不会排队补执行。

Stream Deck + 旋钮可调节音源和输出音量、捂耳程度。Neo 的 Infobar 用于状态显示，也附有 XL 初始布局。播放时不能加载音源组合。

自制工具可通过同一 PC 和 Windows 用户的本地 WebSocket API 控制。随附离线说明书介绍连接信息，并提供 PowerShell 7 的 control.ps1 示例。不接受浏览器连接。

## 精简视图与窗口置顶

按顶部的“精简视图”，会切换成直播时不占地方的小窗口。在小窗口中也可以进行开始、静音、播放音源和联动通话等操作。按“返回完整视图”恢复原样。

勾选“窗口置顶”后，VOrbit ASMR 的窗口会始终显示在其他窗口前面。
