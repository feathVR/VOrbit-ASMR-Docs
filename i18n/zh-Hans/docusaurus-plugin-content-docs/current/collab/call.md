# 联动通话

向远程伙伴发送立体声 ASMR。连接步骤取决于通话方式和版本。

![“联动”界面](/img/screenshots/zh-Hans/collab-zh-Hans.png)

_当前应用画面。可用功能取决于发行版本。_

## 通话方式和版本 {#call-modes}

当前源码的联动页面包含“低延迟通话”和“稳定通话”，都使用 48 kHz 立体声 Opus。这些新方式仍在开发，尚未完成公开发行集成及跨 PC 实际通话验证。可用方式取决于发行版本。

| 方式 | 条件和行为 |
| --- | --- |
| **低延迟通话** | 需要启动 Steam、配套组件及所有权。包括自己最多 4 人。主持人离开时房间结束。 |
| **稳定通话** | 通过发行方配置的服务器进行立体声通话，人数上限取决于服务器。当前接收端约缓冲 200 ms 后播放，延迟较大。未配置服务器的版本无法使用。 |

### 新方式的连接步骤

1. 所有人选择输入和输出并启动音频处理。使用 VST 桥接时先连接 DAW。
2. 选择相同通话方式。创建邀请、连接中或通话中不能切换。
3. 主持人生成邀请码，只私下发送给参与者。参与者粘贴后连接。新方式不需要回传应答码。
4. 用“复制房间邀请码”邀请更多人。断开即可退出。掉线后尚不支持自动恢复。

免费版不能创建房间或发码，只能加入兼容的稳定通话房间，不能加入产品版的低延迟房间。免费版发行和参与资格配置也属于公开前待完成事项。两种方式的码不兼容。延迟或丢包显示“—”表示未测量，并非零。

## 旧版一对一通话 {#legacy-call}

下面适用于需要交换邀请码和应答码的旧版，与新方式步骤不同。

![联动通话的流程](/img/screenshots/zh-Hans/help-collab-zh-Hans.png)

_旧版邀请与应答码交换步骤。新方式见上文。_

1. **双方都先按“开始”**
   双方先选择麦克风和输出设备，然后按顶部的“开始”。建议使用耳机。
2. **发送邀请码（邀请方）**
   在“联动”标签中按“创建邀请码”，把复制好的码通过 Discord 私信等方式只发给对方。
3. **粘贴码并回传应答（被邀请方）**
   在“粘贴对方发来的码”中粘贴收到的码，然后按“连接”。应答码会自动复制，请把它回传给邀请方。
4. **粘贴应答码（邀请方）**
   粘贴收到的应答码并按“连接”。双方都显示“通话中”即完成。

:::warning 邀请码相当于备用钥匙
知道邀请码的人就能加入通话。请不要贴到公开频道。连接失败的码不要重复使用，请重新创建。
:::

## 通话中可以做的事

- 调整对方音量和静音
- 查看延迟和丢包率
- 按“断开”结束通话

在“音源”标签中播放的声音，通话时也会发送给对方。

## 使用实体双耳麦克风时

如果你已经有双耳麦克风或立体声录音环境，请勾选“使用实体双耳麦克风（不做空间化，原样发送）”。麦克风的左右声道会原样发送给对方。使用普通麦克风时请不要勾选。

“开始”期间无法更改此设置。

## 无法连接时 {#cannot-connect}

低延迟通话请检查 Steam、所有权、组件、邀请和空位。稳定通话若提示服务器未配置，需要支持该功能的发行版本。新方式需确认代码与方式一致，取消或断开后重试。仅在旧版直连通话失败时，可尝试固定网络或 IPv6。
