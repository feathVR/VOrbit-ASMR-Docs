# 联动通话

与远方的对方一对一通话，保持立体感一起呈现 ASMR。只需交换一次邀请码和应答码即可连接，不需要专用账号。

![联动通话的流程](/img/screenshots/zh-Hans/help-collab-zh-Hans.png)

_“使用方法”标签中的“与远方的对方联动通话”。邀请方发送邀请码，被邀请方回传应答码。_

## 连接步骤

1. **双方都先按“开始”**
   双方先选择麦克风和输出设备，然后按顶部的“开始”。建议使用耳机。
2. **发送邀请码（邀请方）**
   在“联动”标签中按“创建邀请码”，把复制好的码通过 Discord 私信等方式只发给对方。
3. **粘贴码并回传应答（被邀请方）**
   在“粘贴对方发来的码”中粘贴收到的码，然后按“连接”。应答码会自动复制，请把它回传给邀请方。
4. **粘贴应答码（邀请方）**
   粘贴收到的应答码并按“连接”。双方都显示“通话中”即完成。

![“联动”界面](/img/screenshots/zh-Hans/collab-zh-Hans.png)

_“联动”界面。有“创建邀请码”按钮和粘贴对方发来的码的输入框。_

:::warning 邀请码相当于备用钥匙
知道邀请码的人就能加入通话。请不要贴到公开频道。连接失败的码不要重复使用，请重新创建。
:::

## 通话中可以做的事

- 调整对方音量和静音
- 查看延迟和丢包率
- 按“断开”结束通话

在“音源”标签中播放的声音，通话时也会发送给对方。

## 使用实体双耳麦克风时

如果你已经有双耳麦克风或立体声录音环境，请勾选“使用实体双耳麦克风（不做空间化，原样发送）”。麦克风的左右声道会原样发送给对方。使用普通麦克风时请不要勾选。

“开始”期间无法更改此设置。

## 无法连接时 {#cannot-connect}

- 确认双方都已按“开始”，然后用新的邀请码从头再试。
- 通话采用与对方直接连接的方式（P2P）。双方都是移动网络等难以直连的组合时，可能无法连接。请让其中一方试试固定宽带或支持 IPv6 的网络。
- 通话中断时，请重新创建邀请码再连接。
