# 音源的移动方式

VOrbit ASMR 可以让声音绕着听者的头部转动，也可以在平面上移动。两者都在“位置”标签中设置。

## 围绕头部转动（推荐）

默认使用这种方式。勾选“围绕头部转动（推荐）”后，声音不在平面上，而是在以头部为中心的球面上移动。

- 左右和上下的数值会变成以听者为中心的角度。转动的角度由“移动范围”中的“左右环绕”“上下环绕”决定。
- 距离由“基准距离”决定，左右或上下移动时不变。因此音量稳定，声音会绕着耳边转动。
- 只有分配了深度轴时，声音才会在“深度变化幅度”的范围内相对基准距离靠近或远离。

摄像头对深度的估计往往不可靠，因此适合只让追踪负责左右和上下，距离用“基准距离”来决定的用法。

## 平面移动

取消勾选“围绕头部转动（推荐）”后，左右和上下的数值会直接对应到以米为单位的位置。深度也会在设定范围内前后移动。适合不想让声音转动、只想直接移动位置的情况。

## 仿真人头朝向

在“仿真人头朝向”中选择听者朝向哪一边。

- **正面**：听者与虚拟形象面对面。
- **背面**：声音从背后传来。

“基准距离”是平常姿势时到声音的距离。

## 位置面板的看法

“位置”标签中的两个面板，左侧表示左右和上下，右侧表示左右和深度。红点是声音（追踪中为蓝色），带编号的圆是在“音源”标签中读取的单声道音源。

“显示范围”为“自动”时，会根据使用的轴和设置，按声音实际能到达的范围决定面板的比例。设为“手动”后，可以自己决定从中心到边缘的范围。

## 在直播画面中显示仿真人头麦克风 {#dummy-head-overlay}

启用“在直播画面中显示仿真人头麦克风”后，会在所连接应用（VTube Studio / nizima LIVE）的画面中放置仿真人头麦克风的图片。

- 切换正面和背面时，图片也会随之替换。
- 位置和大小请在该应用中直接拖动调整。
- 在 nizima LIVE 中图片粘在虚拟形象上时，取消道具操作中的“跟随模型”即可让它停留在原处。
- 图片位于“打开图片文件夹”所打开的文件夹中，可以用相同文件名替换成自己画的图。
