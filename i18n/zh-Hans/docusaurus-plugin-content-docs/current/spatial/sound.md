# 声音设置（HRTF・房间混响）

在“声音”标签中选择声音本身的听感。

![“声音”界面](/img/screenshots/zh-Hans/sound-zh-Hans.png)

_当前应用画面。可用功能取决于发行版本。_

## HRTF（头部相关传输函数）

HRTF 是描述声音如何因头部和耳朵的形状而变化的数据。每个人的听感有差异，请选择自己最容易分辨位置的一种。

| 选项 | 内容 |
| --- | --- |
| **Steam Audio 内置** | 默认。Steam Audio 内置的 HRTF |
| **Neumann KU100** | 用仿真人头麦克风 KU100 测得的 HRTF |
| **KEMAR** | 用研究用仿真人头 KEMAR 测得的 HRTF |

建议一边用耳机把声音向左右、前后移动，一边切换比较，选择位置最清楚、听起来最自然的一种。

## 房间混响

为声音加上房间的反射。默认为“无混响”。

- 无混响
- 更衣室
- 浴室
- 录音间
- 杂物较多的小房间
- 混响室
- 音乐厅
- 隧道

## 输出音量

VOrbit ASMR 输出的全部声音的音量。

## 空间化

取消勾选后，不做空间化，直接输出麦克风的声音。也可用来比较有无空间化的区别。

## 安全限制器 {#safety-limiter}

将人声、音源和通话对方声音的最终混音中的突发峰值限制在 −1 dBFS 以下。默认开启，保持左右音量比例，并在工作时显示衰减量。无论开关状态如何，都有 5 ms 前瞻延迟。无法控制后续设备或直播软件增加的音量。

## 捂耳 {#ear-cover}

在房间混响下方模拟用手捂住听众耳朵的声音。低沉的轰鸣及接触、揭开声伴随人声、音源 1–4、混响和通话对方声音变闷。发送给通话对方的声音不受影响。

- 左耳、右耳或双耳按钮用于捂住，再按一次松开。每只耳朵恢复到滑块最后设置的非零位置（初次为 100%）。双耳都被捂住时，双耳按钮同时松开；否则捂住尚未捂住的耳朵。
- “左耳”和“右耳”滑块设置手的位置（0–100%），移动速度也影响声音。双击恢复到 0%。
- “左右联动”默认开启。移动任一滑块，左右都变化相同的量，保持差值；到达端点的一侧停在那里。联动仅适用于滑块。
- “捂住时间”和“松开时间”决定按钮操作时低音升起和消退的时间。“低鸣声大小”“剥离声大小”“使用精油音色”用于调整音量和质感。
- 快捷键和 Stream Deck 支持按住时捂耳，松开后恢复按下前的状态。

启动时双耳都处于开放状态。联动、声音调整和捂住目标位置会保存，当前捂耳程度不保存。
