# 选择音频路径

VOrbit ASMR 可以按使用方式选择音频的通路。两者没有音质优劣之分，请选择适合你平时直播和录音环境的一种。在“设备”标签的“音频路径”中切换。

| 音频路径 | 适合的用法 | 输入输出的设置位置 |
| --- | --- | --- |
| **普通** | 只用 VOrbit ASMR 快速上手 | VOrbit ASMR 的“设备”界面 |
| **DAW（VST 桥接）** | 接入 DAW 的轨道或现有效果器链 | DAW／VST 宿主 |

![“设备”界面的设置](/img/screenshots/zh-Hans/device-card-zh-Hans.png)

_选择“普通”时的“设备”界面。依次是音频路径、降噪、输入输出设备、防掉音和如何接入直播。_

## 选择“普通”时

在“输入设备（麦克风）”中选择麦克风，在“输出设备”中选择耳机，然后按顶部的“开始”。首次确认时保持“系统默认”也可以。重新连接设备后，请按“重新检测”。

### 统一采样率

界面上会显示麦克风和输出的采样率。请把两者设为相同的值（支持：44100 / 48000 / 88200 / 96000 Hz）。采样率可在 Windows 的声音设置或音频接口的设置界面中更改。更改后，先按“停止”，再重新按“开始”。

### 防掉音模式

持续出现噼啪声或掉音时，请开启“防掉音模式”。它会分别运行麦克风和输出，并在中间留出余量，因此延迟增加约 30 ms。麦克风和输出是不同设备时也能保持稳定。

## 选择“DAW（VST 桥接）”时

VOrbit ASMR 不会自己打开音频设备。它从插在 DAW 中的 **VOrbit Bridge** 接收音频，把空间化后的音频送回同一位置。设备、采样率和缓冲区都在 DAW 中设置。

使用音频接口时，这种方式可能更稳定。请继续阅读[使用 VST 桥接](./vst-bridge)。

:::note
“开始”期间无法更改音频路径、输入输出设备、降噪和防掉音模式。请先按“停止”再更改。
:::
