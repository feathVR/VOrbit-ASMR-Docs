# Calibration

Calibration tells VOrbit ASMR how to interpret the values sent by a tracking application as movement in the audio space.

Before calibrating, put the avatar in its normal front-facing pose. Each assigned axis is calibrated independently; an unassigned axis is always treated as centered.

## Recommended procedure

1. Assign a parameter to horizontal movement.
2. Return the avatar to its normal front-facing pose.
3. Complete horizontal calibration.
4. Move left and right and confirm that the sound travels through the expected range.
5. Add and calibrate vertical or depth axes only when necessary.

Calibration is stored for each combination of tracking source and selected parameter names. If you change a parameter, calibrate the new combination again.
