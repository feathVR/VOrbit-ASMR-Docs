# Frequently asked questions

## Can I review the workflow before purchase?

Yes. This public guide explains the required applications, connection methods, and setup flow so that you can review them before purchase.

## Do I need to configure X, Y, and Z from the beginning?

No. Start with the X axis and confirm left-to-right movement. Add Y or Z when the tracking source provides a stable value you actually need.

## What happens to an unassigned axis?

An axis set to `—` is treated as centered. Old calibration values do not affect an unassigned axis.

## Where can I find the Stream Deck plugin?

The Stream Deck plugin is planned as a separate public project from the application and this guide. This page will link to it after publication.

## How do I report a problem?

Report documentation issues in this site's GitHub repository. For product support, use the support contact provided with the distribution.
