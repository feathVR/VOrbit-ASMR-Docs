# VOrbit ASMR User Guide

VOrbit ASMR is a virtual dummy-head microphone for Windows that moves the apparent position of a voice with a 2D avatar. It receives motion from an avatar or tracker and places the sound source around the listener, rendering the movement as binaural audio.

This guide covers installation, first-time setup, tracking connections, calibration, spatial mapping, audio output, and troubleshooting. It is also intended to help you check the required environment and workflow before purchase.

## Choose a goal

- [Make your first sound](getting-started/first-sound) — basic setup after installation
- [Choose a tracking method](tracking/overview) — connect VTube Studio, VMC, or nizima LIVE
- [Calibrate movement](tracking/calibration) — set the center position and movement range
- [Understand source movement](spatial/overview) — orbiting around the head and Cartesian placement
- [Solve a problem](troubleshooting/common-issues) — no sound, no movement, or an incorrect position

## How to read this guide

If you are new to VOrbit ASMR, start with “Make your first sound” and follow the steps in order. For a specific setting, use the sidebar to jump directly to the relevant page.

:::info
The VOrbit ASMR application is distributed separately from this documentation. This guide is public so that you can review the setup and requirements before purchase or installation.
:::
