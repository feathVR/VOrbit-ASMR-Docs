# Perguntas frequentes

## Posso conferir o funcionamento antes de comprar?

Sim. Este guia público explica os aplicativos necessários, os métodos de conexão e o passo a passo da configuração para você conferir antes de comprar.

## Como altero o idioma da interface?

Na primeira inicialização, o aplicativo usa o idioma de exibição do Windows. Se esse idioma não for compatível, usa inglês.

Para alterá-lo, abra **Sobre**, na parte inferior da barra de navegação à esquerda, e escolha uma opção na lista suspensa **Idioma**. A alteração é aplicada na hora e lembrada na próxima inicialização.

Os 8 idiomas disponíveis são 日本語 / English / 简体中文 / 繁體中文 / 한국어 / Русский / Español / Português (Brasil).

## Preciso configurar horizontal, vertical e profundidade desde o início?

Não. Comece com o eixo horizontal e confirme o movimento da esquerda para a direita. Adicione vertical ou profundidade quando a fonte de rastreamento fornecer um valor estável de que você realmente precise.

## O que acontece com um eixo não atribuído?

Um eixo em `—` é tratado como centralizado. Valores de calibração antigos não afetam um eixo não atribuído.

## Onde encontro o plugin do Stream Deck?

O plugin Stream Deck vem com o aplicativo. Instale e coloque ações nas teclas. Veja [Stream Deck e controle externo](features/other#stream-deck).

## Como relato um problema?

Relate problemas da documentação no repositório deste site no GitHub. Para o suporte do produto, use o contato informado na distribuição.
