# Preguntas frecuentes

## ¿Puedo revisar el funcionamiento antes de comprar?

Sí. Esta guía pública explica las aplicaciones necesarias, los métodos de conexión y los pasos de configuración para que puedas revisarlos antes de comprar.

## ¿Tengo que configurar horizontal, vertical y profundidad desde el principio?

No. Empieza con el eje horizontal y confirma el movimiento de izquierda a derecha. Añade vertical o profundidad cuando la fuente de seguimiento dé un valor estable que realmente necesites.

## ¿Qué pasa con un eje sin asignar?

Un eje en `—` se considera centrado. Los valores de calibración antiguos no afectan a un eje sin asignar.

## ¿Dónde encuentro el plugin de Stream Deck?

El plugin de Stream Deck se publicará como un proyecto público separado de la aplicación y de esta guía. Esta página lo enlazará cuando esté disponible.

## ¿Cómo reporto un problema?

Reporta los problemas de la documentación en el repositorio de GitHub de este sitio. Para el soporte del producto, usa el contacto indicado con la distribución.
