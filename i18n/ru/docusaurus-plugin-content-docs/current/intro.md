## Устройство приложения

Разделы переключаются вкладками слева. Вверху — элементы управления, которые нужны на любом экране.

| Вкладка | Назначение |
| --- | --- |
| **Позиция** | Панели положения голоса, режим управления (авто / ручной), подключение трекинга, калибровка, диапазон перемещения |
| **Звук** | HRTF, акустика помещения, громкость вывода, включение и выключение пространственной обработки |
| **Устройства** | Аудиомаршрут (обычный / DAW), микрофон и вывод, шумоподавление, защита от пропаданий, вывод на трансляцию |
| **Коллаб** | Звонок один на один с удалённым собеседником |
| **Аудио** | Загрузка и воспроизведение до четырёх аудиофайлов |
| **Горячие клавиши** | Назначение клавиш для действий приложения |
| **Справка** | Обучение и инструкции по задачам |
| **О программе** | Версия и экспорт диагностического ZIP |

Кнопка «Старт» вверху запускает обработку звука, «Стоп» — останавливает. «Отключить звук» глушит всё, что идёт на трансляцию и в звонок. «Компактный вид» переключает на маленькое окно, которое не мешает во время трансляции, а «Поверх всех окон» держит окно поверх остальных.
