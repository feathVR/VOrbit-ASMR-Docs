# Источники трекинга

VOrbit ASMR поддерживает несколько способов трекинга. После подключения приложение получает доступные параметры из каждого источника, и их можно по отдельности назначить на горизонталь, вертикаль и глубину.

## Поддерживаемые источники

| Источник | Подключение | Горизонталь при первом подключении |
| --- | --- | --- |
| VTube Studio | PC API WebSocket | `FacePositionX` |
| VMC | OSC/UDP (порт по умолчанию 39539) | `Head.RotZ` |
| nizima LIVE | Plugin WebSocket | `Cubism.ParamAngleX` |

При первом подключении назначается только горизонталь, а вертикаль и глубина стоят на `—` (не используются). Если источник передаёт подходящие значения, на вертикаль и глубину тоже можно назначить параметры.

## Подключение

1. Сначала запустите приложение трекинга и модель.
2. На вкладке «Позиция» переключите «Режим управления» на «Авто (трекинг)».
3. Выберите приложение в поле «Источник трекинга» и нажмите «Подключить».
4. Когда появится статус «Приём данных», подключение установлено. Точка голоса на панелях станет синей вместо красной и перестанет перетаскиваться (пронумерованные кружки аудио по-прежнему можно двигать).

## Разрешите подключение в приложении

- **VTube Studio**: включите API в версии для ПК и одобрите запрос плагина при первом подключении.
- **VMC**: включите отправку VMC в передающем приложении. Порт по умолчанию — UDP 39539; его можно изменить в «Параметрах подключения».
- **nizima LIVE**: разрешите подключение плагина при первом запуске.

## Выбор параметров

После подключения появится блок «Используемые параметры», где для горизонтали, вертикали и глубины выбирается свой параметр.

- Для начала рекомендуется только горизонталь. Ось со значением `—` не двигается.
- Чтобы следовать поворотам головы модели, берите параметры Angle (например, `ParamAngleX`), а чтобы следовать перемещению в кадре — Position (например, `FacePositionX`).
- Чтобы управлять мышью без камеры, в VTube Studio можно выбрать `MousePositionX` / `MousePositionY`.
- Вертикаль и глубина чувствительны к колебаниям позы и расстояния до камеры, поэтому добавляйте их только при стабильном сигнале.

После смены параметра заново выполните [калибровку](./calibration).

## С чего начать с VMC

Удобный параметр VMC зависит от передающего приложения и модели. По умолчанию на горизонталь назначается `Head.RotZ` (наклон головы). Если движение слишком слабое или его нет, попробуйте `Hips.PosX`.

В обоих случаях сначала назначайте только горизонталь, а вертикаль и глубину оставляйте на `—`.

### Пример: iFacialMocap и Warudo

| Пункт | Значение |
| --- | --- |
| Способ захвата / камера | iFacialMocap |
| Подключение к VOrbit ASMR | Отправка из Warudo по протоколу VMC |
| Горизонталь | `Head.RotZ` |
| Вертикаль | `—` |
| Глубина | `—` |

Включите отправку VMC в Warudo, затем в VOrbit ASMR выберите источник «VMC Protocol» и подключитесь.

## Приём VMC в другом приложении {#vmc-forwarding}

Когда VOrbit ASMR принимает данные VMC на порту, другие приложения уже не могут принимать их на том же порту. Если данные нужны ещё одному приложению на этом ПК, включите «Пересылать полученные данные на порт» в «Параметрах подключения» и укажите порт, который слушает это приложение.
