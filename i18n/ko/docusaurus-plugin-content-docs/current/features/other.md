# 음원·단축키·간단히 보기

## 음원(오디오 파일 재생)

‘음원’ 탭에서는 오디오 파일 4개를 각각 재생할 수 있습니다. 효과음이나 환경음을 목소리와 함께 공간 안에 둘 수 있습니다.

![‘음원’ 화면](/img/screenshots/ko/playback-ko.png)

_현재 앱 화면. 사용 가능한 기능은 배포판에 따라 다릅니다._

- 각 칸의 ‘파일 선택’을 누르거나, 오디오 파일을 칸에 끌어다 놓아 불러옵니다.
- 지원 형식은 WAV / MP3 / M4A / AAC / FLAC / WMA(Windows가 지원하는 코덱)이며, 파일 하나당 10분까지입니다.
- **모노** 음원은 위치를 움직일 수 있습니다. ‘위치’ 탭의 패드에 번호가 붙은 원으로 표시되며 언제든 드래그할 수 있습니다.
- **스테레오** 음원은 원래의 좌우 폭을 유지해 재생합니다. 위치는 움직일 수 없습니다.
- 재생하려면 위쪽의 ‘시작’으로 오디오 처리를 돌려 두어야 합니다.
- 재생음은 마이크와 같은 출력으로 섞이며, 콜라보 통화 중에는 상대에게도 보내집니다. 음량은 각 칸에서 조정합니다.
- 파형을 클릭하거나 드래그하면 재생 위치를 고를 수 있습니다.

## 재생·일시정지·음량 {#playback-controls}

재생 중 버튼은 **일시 정지**로 바뀝니다. 일시정지는 위치를 유지하며 재생하면 이어집니다. **정지**는 처음으로 돌아갑니다. 파형을 클릭하거나 드래그 후 놓으면 재생 중에는 이동하고, 정지·일시정지 중에는 다음 시작 위치만 선택합니다. 스테레오 파형은 위가 왼쪽 L, 아래가 오른쪽 R입니다. 높이는 파일의 최대 피크에 맞춘 표시이며 출력 음량이 아닙니다.

음량은 dB로 조절합니다(−60~+20 dB, 0 dB는 원래 음량, −60 dB는 무음). 각 음원의 **울림**으로 방 잔향 적용을 선택합니다. 모노 음원은 음원 화면의 정면·위에서 본 패드에서도 드래그할 수 있습니다. 이 패드는 자신의 목소리를 표시하지 않으며 표시 범위를 위치 화면과 별도로 저장합니다.

## 프리셋과 음원 세트 {#source-sets}

**프리셋**에서 동봉된 소리를 고릅니다. Mosco의 “VR向けASMRループ音源集” 1–3집은 앱 안에서 재생하기 위한 것으로 다른 용도로 추출할 수 없습니다. 앱 정보에 제작자와 자료집 링크가 있습니다. 프리셋 팩이 없는 배포판에는 메뉴가 나오지 않습니다.

**음원 세트**는 음원 1–4의 소리·음량·루프·위치·잔향을 함께 저장합니다.

1. 재생 중인 음원을 모두 멈추고 **세트 불러오기**에서 동봉되거나 등록된 세트를 고릅니다. **파일에서 불러오기…**로 .vorbitset 파일도 엽니다.
2. 조합을 바꾼 뒤 **세트 저장**를 누릅니다. 저장한 세트는 Stream Deck용으로도 등록됩니다.
3. **기존 세트 등록…**로 기존 세트를 등록합니다. **등록 해제**는 등록만 해제하며 원본 세트와 오디오 파일은 삭제하지 않습니다.

음원이 재생 중일 때는 세트를 불러올 수 없습니다. 오디오 파일 자체는 세트에 복사하지 않으므로 이동·삭제하면 사용할 수 없게 될 수 있습니다.

## 단축키

‘단축키’ 탭에서는 앱의 조작을 키보드로 실행하도록 할당합니다. 다른 앱을 조작하는 동안에도 동작합니다.

![‘단축키’ 화면](/img/screenshots/ko/hotkeys-ko.png)

_현재 앱 화면. 사용 가능한 기능은 배포판에 따라 다릅니다._

1. ‘단축키 사용’에 체크합니다.
2. 할당하려는 조작 행 오른쪽의 키 칸을 누릅니다.
3. 쓰고 싶은 키를 눌렀다 뗍니다(Ctrl·Alt·Shift 조합도 쓸 수 있습니다).

Esc로 취소하고 ×로 할당을 해제합니다. Windows 키, Esc, F12 등 예약된 키는 쓸 수 없습니다. 다른 앱과 겹쳐 등록되지 않으면 다른 키를 고른 뒤 ‘충돌 다시 확인’을 누르세요.

## 전체 음소거 {#master-mute}

상단 스피커 버튼은 자신의 목소리·음원·잔향·상대 목소리와 상대에게 보내는 소리를 모두 끕니다. 버튼이 빨갛게 되고 창 제목에 음소거가 표시됩니다. 다시 누르면 복원됩니다. 파일 재생은 무음으로 계속됩니다. 통화에서 자신의 마이크만 끄는 것과 별개입니다. 시작 시 음소거는 해제됩니다.

기침할 때 등에는 단축키나 Stream Deck에 누르는 동안만 음소거를 배정합니다. 귀 막기 조작도 배정할 수 있습니다. 일반 단축키는 길게 눌러도 반복되지 않습니다. 배정 중에는 단축키가 잠시 멈추고 취소나 충돌 시 기존 배정을 유지합니다.

## Stream Deck과 외부 조작 {#stream-deck}

동봉된 Stream Deck 플러그인을 설치하고 키에 동작을 배치합니다. 전체 음소거·귀 막기·음원 재생과 음량·세트 불러오기 등을 조작합니다. 앱 실행 시 자동 연결합니다. 빨간 연결 아이콘은 연결 안 됨이며, 끊긴 동안 누른 동작은 나중에 실행되지 않습니다.

Stream Deck + 다이얼로 음원·출력 음량과 귀 막기 정도를 조절합니다. Neo Infobar는 상태 표시용입니다. XL 초기 배치도 동봉됩니다. 재생 중에는 세트를 불러올 수 없습니다.

자작 도구도 같은 PC와 Windows 사용자의 로컬 WebSocket API를 이용할 수 있습니다. 동봉 오프라인 설명서에 연결 정보와 PowerShell 7용 control.ps1 예제가 있습니다. 브라우저 연결은 거부됩니다.

## 간단히 보기와 항상 위

위쪽의 ‘간단히 보기’를 누르면 방송 중에 자리를 차지하지 않는 작은 화면으로 바뀝니다. 작은 화면에서도 시작, 음소거, 음원 재생, 콜라보 통화 등을 조작할 수 있습니다. ‘전체 보기로 돌아가기’로 원래대로 돌아갑니다.

‘항상 위’에 체크하면 VOrbit ASMR 창이 다른 창보다 앞에 계속 표시됩니다.
