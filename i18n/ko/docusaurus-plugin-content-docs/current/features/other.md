# 음원·단축키·간단히 보기

## 음원(오디오 파일 재생)

‘음원’ 탭에서는 오디오 파일 4개를 각각 재생할 수 있습니다. 효과음이나 환경음을 목소리와 함께 공간 안에 둘 수 있습니다.

![‘음원’ 화면](/img/screenshots/ko/playback-ko.png)

_‘음원’ 화면. 4개의 칸에 오디오 파일을 하나씩 불러옵니다._

- 각 칸의 ‘파일 선택’을 누르거나, 오디오 파일을 칸에 끌어다 놓아 불러옵니다.
- 지원 형식은 WAV / MP3 / M4A / AAC / FLAC / WMA(Windows가 지원하는 코덱)이며, 파일 하나당 10분까지입니다.
- **모노** 음원은 위치를 움직일 수 있습니다. ‘위치’ 탭의 패드에 번호가 붙은 원으로 표시되며 언제든 드래그할 수 있습니다.
- **스테레오** 음원은 원래의 좌우 폭을 유지해 재생합니다. 위치는 움직일 수 없습니다.
- 재생하려면 위쪽의 ‘시작’으로 오디오 처리를 돌려 두어야 합니다.
- 재생음은 마이크와 같은 출력으로 섞이며, 콜라보 통화 중에는 상대에게도 보내집니다. 음량은 각 칸에서 조정합니다.
- 파형을 클릭하거나 드래그하면 재생 위치를 고를 수 있습니다.

## 단축키

‘단축키’ 탭에서는 앱의 조작을 키보드로 실행하도록 할당합니다. 다른 앱을 조작하는 동안에도 동작합니다.

![‘단축키’ 화면](/img/screenshots/ko/hotkeys-ko.png)

_‘단축키’ 화면. 조작마다 키를 할당합니다._

1. ‘단축키 사용’에 체크합니다.
2. 할당하려는 조작 행 오른쪽의 키 칸을 누릅니다.
3. 쓰고 싶은 키를 눌렀다 뗍니다(Ctrl·Alt·Shift 조합도 쓸 수 있습니다).

Esc로 취소하고 ×로 할당을 해제합니다. Windows 키, Esc, F12 등 예약된 키는 쓸 수 없습니다. 다른 앱과 겹쳐 등록되지 않으면 다른 키를 고른 뒤 ‘충돌 다시 확인’을 누르세요.

## 간단히 보기와 항상 위

위쪽의 ‘간단히 보기’를 누르면 방송 중에 자리를 차지하지 않는 작은 화면으로 바뀝니다. 작은 화면에서도 시작, 음소거, 음원 재생, 콜라보 통화 등을 조작할 수 있습니다. ‘전체 보기로 돌아가기’로 원래대로 돌아갑니다.

‘항상 위’에 체크하면 VOrbit ASMR 창이 다른 창보다 앞에 계속 표시됩니다.
