# 콜라보 통화

원격 상대에게 스테레오 ASMR을 보냅니다. 연결 절차는 통화 방식과 배포판에 따라 다릅니다.

![‘콜라보’ 화면](/img/screenshots/ko/collab-ko.png)

_현재 앱 화면. 사용 가능한 기능은 배포판에 따라 다릅니다._

## 통화 방식과 배포판 {#call-modes}

현재 소스의 콜라보 화면에는 **저지연 통화**, **안정 통화**가 있습니다. 모두 48 kHz 스테레오 Opus를 사용합니다. 새 방식은 개발 중으로 공개 배포 통합과 별도 PC 간 실제 통화 검증이 아직 완료되지 않았습니다. 사용 가능 여부는 배포판에 따라 다릅니다.

| 방식 | 조건과 동작 |
| --- | --- |
| **저지연 통화** | Steam 실행, 연동 구성요소, 소유권이 필요합니다. 자신 포함 최대 4명. 호스트가 나가면 방이 끝납니다. |
| **안정 통화** | 배포자가 설정한 서버를 통한 스테레오 통화. 인원 제한은 서버에 따릅니다. 현재 수신은 약 200 ms를 버퍼링한 뒤 재생하여 지연이 늘어납니다. 서버 미설정 배포판에서는 사용할 수 없습니다. |

### 새 방식 연결 절차

1. 모두 입력·출력을 선택하고 오디오 처리를 시작합니다. VST 브리지는 DAW를 먼저 연결합니다.
2. 같은 통화 방식을 선택합니다. 초대 생성·연결·통화 중에는 바꿀 수 없습니다.
3. 호스트가 초대 코드를 만들어 참여자에게만 보냅니다. 참여자는 붙여 넣고 연결합니다. 새 방식에서는 응답 코드를 돌려보내지 않습니다.
4. **방 초대 코드 복사**로 추가 참여자를 초대합니다. 연결을 끊으면 퇴장합니다. 끊긴 연결의 자동 복구는 아직 없습니다.

무료판은 방 생성·코드 발급을 할 수 없고 호환되는 안정 통화 방에 참여만 가능합니다. 제품판의 저지연 방에는 참여할 수 없습니다. 무료판 배포와 참여 자격 설정도 공개 전 준비 사항입니다. 두 방식의 코드는 호환되지 않습니다. 지연·손실이 “—”이면 미측정이며 0이 아닙니다.

## 기존 1:1 통화 {#legacy-call}

아래는 초대 코드와 응답 코드를 교환하는 기존 배포판의 절차이며 새 방식과 다릅니다.

![콜라보 통화의 흐름](/img/screenshots/ko/help-collab-ko.png)

_기존 초대·응답 코드 교환입니다. 새 방식은 위 설명을 참조하세요._

1. **두 사람 모두 ‘시작’해 두기**
   두 사람 모두 먼저 마이크와 출력 장치를 고르고 위쪽의 ‘시작’을 누릅니다. 헤드폰을 권장합니다.
2. **초대 코드 보내기(초대하는 쪽)**
   ‘콜라보’ 탭에서 ‘초대 코드 만들기’를 누르고, 복사된 코드를 Discord DM 등으로 상대에게만 보냅니다.
3. **코드를 붙여넣고 응답 돌려보내기(초대받은 쪽)**
   ‘상대에게 받은 코드 붙여넣기’에 받은 코드를 붙여넣고 ‘연결’을 누릅니다. 응답 코드가 자동으로 복사되므로 초대한 쪽에 돌려보냅니다.
4. **응답 코드 붙여넣기(초대하는 쪽)**
   받은 응답 코드를 붙여넣고 ‘연결’을 누릅니다. 양쪽에 ‘통화 중’이 표시되면 완료입니다.

:::warning 초대 코드는 통화의 열쇠입니다
초대 코드를 아는 사람은 통화에 들어올 수 있습니다. 공개 채널에 붙여넣지 마세요. 연결에 실패한 코드는 다시 쓰지 말고 새로 만드세요.
:::

## 통화 중에 할 수 있는 일

- 상대 음량 조정과 음소거
- 지연과 패킷 손실률 확인
- ‘연결 끊기’로 통화 종료

‘음원’ 탭에서 재생한 소리도 통화 중에는 상대에게 보내집니다.

## 실제 바이노럴 마이크를 쓰는 경우

이미 바이노럴 마이크나 스테레오 녹음 환경이 있다면 ‘실제 바이노럴 마이크 사용 (공간화하지 않고 그대로 보냄)’에 체크합니다. 마이크의 좌우 채널을 그대로 상대에게 보냅니다. 일반 마이크를 쓸 때는 체크하지 마세요.

이 설정은 ‘시작’한 동안에는 바꿀 수 없습니다.

## 연결되지 않을 때 {#cannot-connect}

저지연 통화는 Steam·소유권·구성요소·초대·빈자리를 확인합니다. 안정 통화 서버 미설정 오류는 지원 배포판이 필요합니다. 새 방식은 코드와 방식이 맞는지 확인하고 취소·연결 해제 후 재시도합니다. 기존 직접 통화만 연결이 안 될 경우 고정 회선이나 IPv6를 시도하세요.
