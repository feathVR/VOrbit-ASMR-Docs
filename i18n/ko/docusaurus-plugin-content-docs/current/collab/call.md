# 콜라보 통화

멀리 있는 상대와 1:1로 통화하며 입체감을 유지한 채 함께 ASMR을 전할 수 있습니다. 초대 코드와 응답 코드를 한 번 주고받기만 하면 연결되며, 전용 계정은 필요 없습니다.

![콜라보 통화의 흐름](/img/screenshots/ko/help-collab-ko.png)

_‘도움말’ 탭의 ‘멀리 있는 상대와 콜라보 통화하기’. 초대하는 쪽이 초대 코드를 보내고, 초대받은 쪽이 응답 코드를 돌려보냅니다._

## 연결 절차

1. **두 사람 모두 ‘시작’해 두기**
   두 사람 모두 먼저 마이크와 출력 장치를 고르고 위쪽의 ‘시작’을 누릅니다. 헤드폰을 권장합니다.
2. **초대 코드 보내기(초대하는 쪽)**
   ‘콜라보’ 탭에서 ‘초대 코드 만들기’를 누르고, 복사된 코드를 Discord DM 등으로 상대에게만 보냅니다.
3. **코드를 붙여넣고 응답 돌려보내기(초대받은 쪽)**
   ‘상대에게 받은 코드 붙여넣기’에 받은 코드를 붙여넣고 ‘연결’을 누릅니다. 응답 코드가 자동으로 복사되므로 초대한 쪽에 돌려보냅니다.
4. **응답 코드 붙여넣기(초대하는 쪽)**
   받은 응답 코드를 붙여넣고 ‘연결’을 누릅니다. 양쪽에 ‘통화 중’이 표시되면 완료입니다.

![‘콜라보’ 화면](/img/screenshots/ko/collab-ko.png)

_‘콜라보’ 화면. ‘초대 코드 만들기’와 상대에게 받은 코드를 붙여넣는 칸이 있습니다._

:::warning 초대 코드는 통화의 열쇠입니다
초대 코드를 아는 사람은 통화에 들어올 수 있습니다. 공개 채널에 붙여넣지 마세요. 연결에 실패한 코드는 다시 쓰지 말고 새로 만드세요.
:::

## 통화 중에 할 수 있는 일

- 상대 음량 조정과 음소거
- 지연과 패킷 손실률 확인
- ‘연결 끊기’로 통화 종료

‘음원’ 탭에서 재생한 소리도 통화 중에는 상대에게 보내집니다.

## 실제 바이노럴 마이크를 쓰는 경우

이미 바이노럴 마이크나 스테레오 녹음 환경이 있다면 ‘실제 바이노럴 마이크 사용 (공간화하지 않고 그대로 보냄)’에 체크합니다. 마이크의 좌우 채널을 그대로 상대에게 보냅니다. 일반 마이크를 쓸 때는 체크하지 마세요.

이 설정은 ‘시작’한 동안에는 바꿀 수 없습니다.

## 연결되지 않을 때 {#cannot-connect}

- 두 사람 모두 ‘시작’했는지 확인하고, 새 초대 코드로 처음부터 다시 시도합니다.
- 통화는 상대와 직접 연결하는 방식(P2P)입니다. 두 사람 모두 모바일 회선 등 직접 연결이 어려운 회선 조합이면 연결되지 않을 수 있습니다. 한쪽이라도 유선 회선이나 IPv6를 쓸 수 있는 회선을 시도해 보세요.
- 통화가 끊기면 초대 코드를 새로 만들어 다시 연결하세요.
