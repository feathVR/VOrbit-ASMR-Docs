# 트래킹 소스

VOrbit ASMR은 여러 트래킹 방식을 지원합니다. 연결하면 각 앱에서 사용할 수 있는 파라미터를 가져와 좌우·상하·깊이 축에 각각 할당할 수 있습니다.

## 지원하는 소스

| 소스 | 연결 방식 | 처음 할당되는 좌우 축 |
| --- | --- | --- |
| VTube Studio | PC API WebSocket | `FacePositionX` |
| VMC | OSC/UDP(기본 수신 포트 39539) | `Head.RotZ` |
| nizima LIVE | Plugin WebSocket | `Cubism.ParamAngleX` |

처음 연결하면 좌우 축만 할당되고, 상하와 깊이는 `—`(사용 안 함)입니다. 소스가 제공하는 값에 따라 상하나 깊이에도 다른 파라미터를 할당할 수 있습니다.

## 연결하기

1. 먼저 트래킹 앱과 모델을 실행합니다.
2. ‘위치’ 탭의 ‘조작 모드’를 ‘자동 (트래킹)’으로 합니다.
3. ‘입력 소스’에서 앱을 선택하고 ‘연결’을 누릅니다.
4. 표시가 ‘수신 중’이 되면 연결된 것입니다. 패드의 목소리 점이 빨간색에서 파란색으로 바뀌고, 드래그로는 움직이지 않습니다(번호가 붙은 원형 음원은 계속 움직일 수 있습니다).

## 앱 쪽에서 연결 허용하기

- **VTube Studio**: PC 버전에서 API를 켜고, 처음 연결할 때 표시되는 플러그인 허가를 승인합니다.
- **VMC**: 송신 앱에서 VMC 송신을 켭니다. 기본 수신 포트는 UDP 39539이며, ‘연결 세부 설정’에서 바꿀 수 있습니다.
- **nizima LIVE**: 처음 플러그인을 연결할 때 허용합니다.

## 사용할 파라미터 선택

연결하면 ‘사용할 파라미터’가 표시되고, 좌우·상하·깊이 축마다 파라미터를 고를 수 있습니다.

- 처음에는 좌우만 권장합니다. `—`로 한 축은 움직이지 않습니다.
- 모델의 고개 돌리기를 따라가려면 Angle 계열(예: `ParamAngleX`), 화면 안의 이동을 따라가려면 Position 계열(예: `FacePositionX`)을 기준으로 삼으세요.
- 카메라 대신 마우스로 움직이려면 VTube Studio의 `MousePositionX` / `MousePositionY`를 고를 수 있습니다.
- 상하와 깊이는 자세나 카메라 거리의 흔들림이 소리에 드러나기 쉬우므로, 입력이 안정적일 때 추가하세요.

파라미터를 바꾸면 [보정](./calibration)을 다시 하세요.

## VMC에서 먼저 시도할 설정

VMC는 송신 앱이나 모델에 따라 쓰기 좋은 파라미터가 다릅니다. 좌우 축에는 기본값 `Head.RotZ`(머리 기울기)가 할당됩니다. 움직임이 작거나 움직이지 않으면 `Hips.PosX`를 시도하세요.

어느 경우든 처음에는 좌우만 할당하고, 상하와 깊이는 `—` 그대로 둡니다.

### iFacialMocap과 Warudo 설정 예

| 항목 | 설정 |
| --- | --- |
| 캡처 방법·카메라 | iFacialMocap |
| VOrbit ASMR 연결 방법 | Warudo에서 VMC 프로토콜로 송신 |
| 좌우 | `Head.RotZ` |
| 상하 | `—` |
| 깊이 | `—` |

Warudo에서 VMC 송신을 켜고, VOrbit ASMR에서는 입력 소스로 ‘VMC Protocol’을 선택해 연결합니다.

## 다른 앱에서도 VMC 받기 {#vmc-forwarding}

VOrbit ASMR이 VMC 데이터를 받으면 같은 포트에서는 다른 앱이 받을 수 없게 됩니다. 같은 PC의 다른 앱에서도 쓰려면 ‘연결 세부 설정’의 ‘받은 데이터 전달 (포트)’를 켜고, 전달할 포트를 그 앱의 수신 포트에 맞추세요.
