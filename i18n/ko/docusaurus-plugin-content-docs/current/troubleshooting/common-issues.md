# 자주 발생하는 문제

앱 안의 ‘도움말’ 탭 ‘잘 작동하지 않을 때’에도 같은 확인 절차가 있습니다.

![‘도움말’ 화면](/img/screenshots/ko/help-ko.png)

_‘도움말’ 탭. 튜토리얼 다시 시작, 이 가이드 열기, 목적별 절차가 있습니다. 바이노럴 확인에는 헤드폰이나 이어폰을 쓰세요._

## 지직거림·끊김

1. ‘장치’에서 마이크와 출력의 샘플레이트를 확인합니다.
2. 둘을 같은 샘플레이트(지원: 44100 / 48000 / 88200 / 96000 Hz)로 맞춥니다. 샘플레이트는 Windows 소리 설정이나 오디오 인터페이스의 설정 화면에서 바꿀 수 있습니다.
3. ‘정지’한 뒤 다시 ‘시작’합니다.
4. 그래도 계속되면 ‘끊김 방지 모드’를 켭니다(지연이 약 30 ms 늘어납니다).

오디오 인터페이스를 쓴다면 [DAW (VST 브리지)](../audio/vst-bridge)가 더 안정적일 수 있습니다.

## 내 목소리가 들리지 않음·소리가 나지 않음

- 위쪽 버튼이 ‘정지’로 표시되는지(동작 중인지) 확인합니다.
- 입력 미터, 출력 미터 순서로 확인합니다. 입력만 움직이면 출력 장치와 ‘소리’ 탭의 출력 음량을 확인합니다.
- 입력·출력 장치가 의도한 기기인지 확인합니다. 장치를 다시 연결했으면 ‘다시 검색’을 누릅니다.
- 위쪽의 ‘음소거’가 켜져 있지 않은지, Windows 쪽 음소거와 음량도 확인합니다.
- 오디오 경로가 ‘DAW (VST 브리지)’라면 DAW의 입출력과 모니터를 확인합니다.

## 트래킹이 연결되지 않음·점이 파란색이 되지 않음

- ‘위치’ 탭의 조작 모드가 ‘자동 (트래킹)’인지 확인합니다.
- 입력 소스 표시가 ‘수신 중’인지 확인합니다.
- 사용하는 축에 `—` 이외의 파라미터가 할당되어 있는지 확인합니다.
- 할당한 축이 ‘보정 완료’인지 확인합니다.

## 목소리는 움직이지만 위치가 부자연스러움

- 아바타의 평소 자세로 [보정](../tracking/calibration)을 다시 합니다.
- ‘움직임 범위’의 ‘반전’과 ‘스무딩’을 확인합니다.
- ‘머리 주위를 돌기 (권장)’의 켜기·끄기가 의도대로인지 확인합니다.
- ‘좌우 회전 각도’, ‘상하 회전 각도’, ‘깊이 변화 폭’을 확인합니다.

## 같은 PC의 다른 앱에서 VMC를 받지 못하게 됨

‘연결 세부 설정’에서 ‘받은 데이터 전달 (포트)’를 켜세요. 자세한 내용은 [트래킹 소스](../tracking/overview#vmc-forwarding)를 참고하세요.

## 콜라보가 연결되지 않음

두 사람 모두 ‘시작’했는지 확인하고, 새 초대 코드로 처음부터 다시 시도합니다. 다른 유선 회선이나 IPv6를 쓸 수 있는 회선도 시도해 보세요. 자세한 내용은 [콜라보 통화](../collab/call#cannot-connect)를 참고하세요.

## 소리가 이중으로 들림·울림

- OBS에서 같은 소리를 두 경로로 받고 있지 않은지 확인합니다([OBS·방송에 소리 싣기](../streaming/obs)).
- 스피커 소리가 마이크로 되돌아가지 않는지 확인합니다. 헤드폰 사용을 권장합니다.

## 해결되지 않을 때

‘정보’ 탭의 ‘진단 ZIP 내보내기’로 진단 정보를 내보내고, 내용을 확인한 뒤 버그 신고에 첨부하세요. 진단 ZIP에는 음성·초대 코드·인증 정보가 포함되지 않습니다.
