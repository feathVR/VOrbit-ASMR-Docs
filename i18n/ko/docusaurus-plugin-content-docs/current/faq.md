# 자주 묻는 질문

## 구매 전에도 조작 방법을 확인할 수 있나요?

네. 이 사용 가이드는 공개되어 있어, 필요한 앱, 연결 방식, 설정 흐름을 구매 전에 확인할 수 있습니다.

## 처음부터 좌우·상하·깊이를 모두 설정해야 하나요?

아니요. 먼저 좌우 축만으로 움직임을 확인하는 것을 권장합니다. 상하와 깊이는 사용하는 트래킹 소스에서 안정적인 값을 얻을 수 있을 때 추가하세요.

## 할당하지 않은 축은 어떻게 되나요?

`—`를 선택한 축은 중앙으로 취급됩니다. 예전 보정값이 남아 있어도 그 축의 위치에는 영향을 주지 않습니다.

## Stream Deck 플러그인은 어디서 확인할 수 있나요?

Stream Deck 플러그인은 앱 본체 및 이 가이드와 별개의 공개 프로젝트로 안내할 예정입니다. 공개 후 이 페이지에 링크하겠습니다.

## 문제를 신고하려면 어떻게 하나요?

이 가이드의 내용에 관한 문제는 이 사이트의 GitHub 저장소에서 신고할 수 있습니다. 제품 본체의 지원 창구는 배포 시 안내를 확인하세요.
