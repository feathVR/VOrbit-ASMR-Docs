# 오디오 경로 선택

VOrbit ASMR은 사용 방식에 맞춰 오디오가 지나가는 길을 고를 수 있습니다. 음질의 우열이 아니라 평소 방송·녹음 환경에 맞는 쪽을 고르세요. ‘장치’ 탭의 ‘오디오 경로’에서 바꿉니다.

| 오디오 경로 | 알맞은 사용법 | 입출력 설정 위치 |
| --- | --- | --- |
| **일반** | VOrbit ASMR만으로 빠르게 사용 | VOrbit ASMR의 ‘장치’ 화면 |
| **DAW (VST 브리지)** | DAW 트랙이나 기존 이펙트 구성에 넣기 | DAW／VST 호스트 |

![‘장치’ 화면의 설정](/img/screenshots/ko/device-card-ko.png)

_‘일반’일 때의 ‘장치’ 화면. 오디오 경로, 소음 줄이기, 입출력 장치, 끊김 방지, 방송에 싣는 방법이 있습니다._

## ‘일반’을 고를 때

‘입력 장치 (마이크)’에서 마이크를, ‘출력 장치’에서 헤드폰이나 이어폰을 고르고 위쪽의 ‘시작’을 누릅니다. 처음 확인할 때는 ‘시스템 기본값’ 그대로도 괜찮습니다. 장치를 다시 연결했으면 ‘다시 검색’을 누릅니다.

### 샘플레이트 맞추기

화면에 마이크와 출력의 샘플레이트가 표시됩니다. 둘을 같은 값(지원: 44100 / 48000 / 88200 / 96000 Hz)으로 맞추세요. 샘플레이트는 Windows 소리 설정이나 오디오 인터페이스의 설정 화면에서 바꿀 수 있습니다. 바꾼 뒤에는 ‘정지’하고 다시 ‘시작’하세요.

### 끊김 방지 모드

지직거림이나 끊김이 계속되면 ‘끊김 방지 모드’를 켭니다. 마이크와 출력을 따로 돌리고 그 사이에 여유를 두기 때문에 지연이 약 30 ms 늘어납니다. 마이크와 출력이 다른 장치여도 안정적입니다.

## ‘DAW (VST 브리지)’를 고를 때

VOrbit ASMR은 오디오 장치를 직접 열지 않습니다. DAW에 넣은 **VOrbit Bridge**에서 오디오를 받아, 공간화한 오디오를 같은 곳으로 돌려보냅니다. 장치, 샘플레이트, 버퍼는 DAW에서 설정합니다.

오디오 인터페이스를 쓴다면 이쪽이 더 안정적일 수 있습니다. 이어서 [VST 브리지 사용하기](./vst-bridge)를 참고하세요.

:::note
‘시작’한 동안에는 오디오 경로, 입출력 장치, 소음 줄이기, 끊김 방지 모드를 바꿀 수 없습니다. 먼저 ‘정지’한 뒤 바꾸세요.
:::
