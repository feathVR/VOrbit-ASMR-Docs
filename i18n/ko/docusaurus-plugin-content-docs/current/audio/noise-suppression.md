# 소음 줄이기

‘주변 소음을 약하게 줄이기’는 PC 팬이나 에어컨 같은 일정한 주변 소음을 억제하는 선택 기능입니다. 기본값은 꺼짐입니다.

## 사용 기준

- 말하지 않을 때도 일정한 팬 소리나 에어컨 소리가 들리면 켜 보세요.
- 숨소리, 속삭임, 세밀한 소리의 질감을 우선한다면 먼저 끈 상태로 확인하세요.
- 켜면 지연이 약 **10 ms** 늘어납니다.

이 설정은 동작 중에는 바꿀 수 없습니다. ‘정지’한 뒤 바꾸면 다음에 ‘시작’할 때부터 반영됩니다. 방송이나 녹음 전에 헤드폰으로 목소리와 작은 소리가 어떻게 들리는지 확인하세요.

:::note
소음 줄이기는 마이크로 들어오는 목소리에 적용됩니다. 스테레오／바이노럴 소재 입력에는 적용되지 않습니다.
:::
