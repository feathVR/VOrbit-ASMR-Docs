# VST 브리지 사용하기

VST 브리지는 DAW나 VST 호스트 안의 마이크 오디오를 VOrbit ASMR로 보내고, 공간화한 오디오를 같은 플러그인 위치로 돌려보냅니다.

<img src="/VOrbit-ASMR-Docs/img/vst-bridge-flow-ko.svg" alt="마이크에서 DAW의 VOrbit Bridge와 DAW 출력을 거쳐 OBS로 소리가 가는 그림. VOrbit ASMR은 Bridge와 오디오를 주고받고, 헤드폰은 별도의 모니터 경로로 표시" width="1400" height="820" />

_오디오 흐름을 나타낸 개념도입니다. [이미지를 열어 확대](/img/vst-bridge-flow-ko.svg)할 수 있습니다._

OBS로 방송하는 경우 **DAW에서 가공된 오디오를 OBS가 받아 오는 경로를 따로 설정**해야 합니다. DAW의 출력 대상이나 가상 오디오 장치 등 환경에 맞는 방법을 고르세요. 헤드폰에서 들린다고 해서 OBS까지 도착한 것은 아닙니다. OBS의 오디오 미터와 짧은 테스트 녹화로 확인하세요.

## 설정 절차

‘장치’ 탭에서 ‘DAW (VST 브리지)’를 고르면 ‘DAW에서 사용하기 (VST 브리지)’에 4단계가 표시됩니다.

1. **‘VOrbit Bridge.vst3’를 DAW의 VST3 폴더에 복사**
   ‘브리지 폴더 열기’를 누르고, 열린 폴더의 **`VOrbit Bridge.vst3`를 폴더째** DAW가 읽는 VST3 폴더에 복사합니다. 이름은 .vst3이지만 안에 파일이 든 폴더입니다. 안의 파일만 꺼내지 마세요.
2. **VOrbit ASMR의 오디오 경로를 ‘DAW (VST 브리지)’로 설정**
   ‘시작’한 동안에는 바꿀 수 없으므로 먼저 ‘정지’하세요.
3. **호스트에서 다시 스캔하고 마이크 트랙에 넣기**
   DAW에서 플러그인을 다시 스캔하고, 마이크 트랙에 **VOrbit Bridge**를 넣습니다. DAW의 입력 모니터도 켭니다.
4. **‘시작’ 누르기**
   DAW에서 연결되면 공간화를 시작할 수 있습니다.

![VST 브리지 설정 화면](/img/screenshots/ko/vst-bridge-ko.png)

_화면에도 복사 원본과 현재 연결 상태가 표시됩니다. 이미지의 경로는 개발 환경의 예이며, 실제 위치는 설치 위치에 따라 다릅니다._

## DAW 쪽 설정

- 입력 장치, 출력 장치, 샘플레이트, 버퍼는 DAW에서 설정합니다.
- 지원 샘플레이트는 **44.1 kHz / 48 kHz**입니다.
- VOrbit ASMR과 연결되지 않았을 때 플러그인은 오디오를 그대로 통과시킵니다.
- 소재 소리와 콜라보 상대의 목소리는 브리지를 넣은 트랙의 출력으로 DAW에 돌아옵니다. DAW 전체 믹스에는 넣지 마세요(상대의 목소리가 상대에게 돌아가 에코가 됩니다).
- DAW가 연결되지 않은 동안에는 ‘음원’ 재생과 콜라보 통화를 쓸 수 없습니다.
- 내보내기(오프라인 처리)와 프리즈에서는 오디오가 그대로 통과합니다.

## 목소리·소재·통화 상대를 따로 녹음하고 싶을 때

같은 폴더의 **`VOrbit Bridge Multi.vst3`**도 함께 복사하고 DAW에서 악기로 불러오세요. 단독으로는 소리가 나지 않습니다.

## 업데이트하거나 그만 쓸 때

- VOrbit ASMR을 업데이트하면 새 `VOrbit Bridge.vst3`를 다시 복사하세요.
- 그만 쓸 때는 복사한 `VOrbit Bridge.vst3`를 직접 삭제하세요. 제거(언인스톨)해도 지워지지 않습니다.

연결되지 않으면 VOrbit ASMR을 정지하고 오디오 경로를 다시 고른 뒤, DAW에서 플러그인을 다시 스캔하세요.
