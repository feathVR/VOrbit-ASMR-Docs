## 화면 구성

왼쪽 탭으로 화면을 바꿉니다. 위쪽에는 어느 화면에서나 쓰는 조작이 모여 있습니다.

| 탭 | 할 수 있는 일 |
| --- | --- |
| **위치** | 목소리 위치 패드, 조작 모드(자동／수동), 트래킹 연결, 보정, 움직임 범위 |
| **소리** | HRTF(머리 전달 함수), 방의 울림, 출력 음량, 공간화 켜기·끄기 |
| **장치** | 오디오 경로(일반／DAW), 마이크와 출력 장치, 소음 줄이기, 끊김 방지, 방송에 싣는 방법 |
| **콜라보** | 멀리 있는 상대와 1:1 통화 |
| **음원** | 오디오 파일을 최대 4개까지 불러와 재생 |
| **단축키** | 키보드로 조작을 실행하는 할당 |
| **도움말** | 튜토리얼과 목적별 절차 |
| **정보** | 버전, 진단 ZIP 내보내기 |

위쪽의 ‘시작’으로 오디오 처리를 시작하고 ‘정지’로 멈춥니다. ‘음소거’는 방송과 통화로 나가는 소리를 모두 멈춥니다. ‘간단히 보기’는 방송 중에 방해되지 않는 작은 화면으로 바꾸고, ‘항상 위’는 다른 창보다 앞에 계속 표시합니다.
