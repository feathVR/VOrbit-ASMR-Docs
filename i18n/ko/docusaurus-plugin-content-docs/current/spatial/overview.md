# 음원의 움직임

VOrbit ASMR에서는 목소리를 청취자의 머리 주위로 돌게 하는 방식과 평면 위에서 움직이는 방식을 고를 수 있습니다. 둘 다 ‘위치’ 탭에서 설정합니다.

<img src="/VOrbit-ASMR-Docs/img/spatial-mapping-ko.svg" alt="위에서 본 그림. 목소리가 머리 주위를 호를 그리며 움직이는 방식과 직선 위를 움직이는 방식의 비교" width="1200" height="650" />

_좌우만 움직였을 때의 개념도입니다. [이미지를 열어 확대](/img/spatial-mapping-ko.svg)할 수 있습니다._

## 머리 주위를 돌기 (권장)

기본으로 이 방식을 씁니다. ‘머리 주위를 돌기 (권장)’에 체크하면 목소리는 평면이 아닌 머리를 중심으로 한 구면 위를 움직입니다.

- 좌우와 상하 값은 청취자를 중심으로 한 각도가 됩니다. 도는 각도는 ‘움직임 범위’의 ‘좌우 회전 각도’, ‘상하 회전 각도’로 정해집니다.
- 거리는 ‘기준 거리’로 정해지며, 좌우나 상하로 움직여도 바뀌지 않습니다. 그래서 음량이 안정되고, 귓가를 돌아가는 움직임이 됩니다.
- 깊이 축을 할당한 경우에만 ‘깊이 변화 폭’만큼 기준 거리에서 가까워지거나 멀어집니다.

웹캠의 깊이 추정은 믿기 어려운 경우가 많으므로, 좌우와 상하만 트래킹에 맡기고 거리는 ‘기준 거리’로 정하는 사용법에 알맞습니다.

## 평면 이동

‘머리 주위를 돌기 (권장)’의 체크를 풀면 좌우와 상하 값을 미터 단위 위치에 바로 할당합니다. 깊이도 설정 범위에 따라 앞뒤로 움직입니다. 목소리를 돌리지 않고 위치를 직접 움직이고 싶을 때 씁니다.

## 더미 헤드 방향

‘더미 헤드 방향’에서 듣는 사람이 어느 쪽을 보고 있는지 고릅니다.

- **앞**: 듣는 사람과 아바타가 마주 봅니다.
- **뒤**: 목소리가 뒤에서 들립니다.

‘기준 거리’는 평소 자세일 때 목소리까지의 거리입니다.

## 위치 패드 보는 법

‘위치’ 탭의 두 패드는 왼쪽이 좌우와 상하, 오른쪽이 좌우와 깊이를 나타냅니다. 빨간 점이 목소리(트래킹 중에는 파란색), 번호가 붙은 원이 ‘음원’ 탭에서 불러온 모노 음원입니다.

‘표시 범위’를 ‘자동’으로 하면 사용하는 축과 설정에서 목소리가 실제로 닿는 범위에 맞춰 패드의 축척을 정합니다. ‘수동’으로 하면 중심에서 끝까지의 범위를 직접 정할 수 있습니다.

## 방송 화면에 더미 헤드 마이크 표시 {#dummy-head-overlay}

‘방송 화면에 더미 헤드 마이크 표시’를 켜면 연결된 앱(VTube Studio / nizima LIVE) 화면에 더미 헤드 마이크 이미지를 놓습니다.

- 앞과 뒤를 바꾸면 이미지도 함께 바뀝니다.
- 위치와 크기는 그 앱에서 직접 드래그해 조정합니다.
- nizima LIVE에서 아바타에 붙어 버리면, 아이템 조작의 ‘모델에 추종’ 체크를 풀면 그 자리에 머뭅니다.
- 이미지는 ‘이미지 폴더 열기’로 열리는 폴더에 있으며, 같은 파일 이름으로 직접 그린 그림으로 바꿀 수 있습니다.
