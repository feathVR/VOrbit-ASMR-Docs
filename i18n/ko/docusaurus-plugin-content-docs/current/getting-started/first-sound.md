# 첫 소리 내기

설치 후 목소리가 공간 음향으로 들리는 데까지 설정합니다. 처음에는 트래킹 없이 손으로 목소리를 움직여 확인하면, 어디서 막혔는지 알기 쉽습니다.

## 한 장으로 보는 간단 설정

<img src="/VOrbit-ASMR-Docs/img/quick-start-ko.svg" alt="VOrbit ASMR의 소리 내기와 자동 트래킹을 5단계로 설명하는 간단 설정 시트" width="1200" height="1600" />

_먼저 1~3에서 소리와 위치 변화를 확인합니다. 자동 트래킹을 쓸 때만 4~5로 진행하세요. [이미지를 열어 확대](/img/quick-start-ko.svg)할 수 있습니다._

## 준비물

- 사용할 마이크와 헤드폰 또는 이어폰
- 자동으로 움직이려면 지원하는 아바타·트래킹 앱(VTube Studio, nizima LIVE, VMC 송신 앱)

:::warning
공간 음향의 위치를 제대로 확인하려면 스피커가 아닌 헤드폰이나 이어폰을 사용하세요.
:::

## 튜토리얼을 따라 진행하기

처음 실행하면 ‘장치’ 화면이 열리고, 창 위쪽에 ‘초기 설정’ 안내가 표시됩니다. 안내는 다음 5단계입니다.

![초기 설정 안내](/img/screenshots/ko/tutorial-ko.png)

_초기 설정 안내. 첫 번째 단계 ‘마이크와 출력 장치 선택’을 표시하고 있습니다._

1. 마이크와 출력 장치 선택
2. 먼저 소리의 움직임을 들어 보기
3. 트래킹 연결
4. 중앙과 동작 범위 기록
5. 방송에 소리 보내기

각 단계의 ‘이 단계 화면으로’를 누르면 해당 설정이 있는 화면으로 이동하고, 조작할 곳이 강조됩니다. 단계를 마치면 안내에 완료 표시가 붙지만, 자동으로 다음 단계로 넘어가지는 않습니다. 확인했으면 ‘확인 — 다음’을 누르세요.

중간에 그만두려면 ‘나중에 (도움말에서 다시 시작)’을 누릅니다. 나중에 ‘도움말’ 탭의 ‘튜토리얼 시작’으로 처음부터 다시 할 수 있습니다.

## 절차

### 1. 마이크와 출력 장치 선택

‘장치’ 탭을 열고 ‘오디오 경로’가 ‘일반’인지 확인합니다. ‘입력 장치 (마이크)’에서 사용할 마이크를, ‘출력 장치’에서 헤드폰이 연결된 장치를 선택합니다. 잘 모르겠으면 ‘시스템 기본값’ 그대로 두어도 됩니다.

DAW 안에서 사용하려면 ‘DAW (VST 브리지)’를 선택하고 [VST 브리지 절차](../audio/vst-bridge)로 진행하세요.

![‘장치’ 화면](/img/screenshots/ko/device-ko.png)

_‘장치’ 화면. ‘일반’에서는 이 화면에서 마이크와 출력 장치를 선택합니다._

### 2. ‘시작’을 누르고 소리 내기

위쪽의 ‘시작’을 누르고 마이크에 대고 “아—” 하고 길게 소리를 냅니다. 헤드폰에서 자기 목소리가 들리고 위쪽의 입력·출력 미터가 움직이면 성공입니다.

### 3. 빨간 점을 드래그해 목소리 움직이기

‘위치’ 탭의 ‘조작 모드’를 ‘수동’으로 합니다. 소리를 길게 낸 채로 위치 패드의 빨간 점(내 목소리)을 잡고 좌우로 움직입니다. 헤드폰 속에서 목소리가 움직이면 VOrbit ASMR의 기본 체험은 완료입니다.

![‘수동’으로 한 ‘위치’ 화면](/img/screenshots/ko/position-manual-ko.png)

_왼쪽 패드는 좌우와 상하, 오른쪽 패드는 좌우와 깊이를 나타냅니다. 빨간 점이 목소리입니다._

### 4. 자동으로 움직이기(선택)

아바타의 움직임에 맞춰 목소리를 움직이려면 [트래킹을 연결](../tracking/overview)하고 [중앙과 동작 범위를 보정](../tracking/calibration)합니다.

### 5. 방송에 소리 보내기

방송하는 경우 [OBS·방송에 소리 싣기](../streaming/obs)를 참고하세요.

:::tip 소음 줄이기는 선택 사항입니다
PC 팬이나 에어컨 같은 일정한 주변 소음이 신경 쓰일 때만 켜세요. 기본값은 꺼짐이며, 켜면 지연이 약 10 ms 늘어납니다. 자세한 내용은 [소음 줄이기](../audio/noise-suppression)를 참고하세요.
:::
