# 常見問題

應用程式內「使用方法」分頁的「無法正常運作時」中也有同樣的檢查步驟。

![「使用方法」畫面](/img/screenshots/zh-Hant/help-zh-Hant.png)

_「使用方法」分頁。可以重新開始教學、開啟本指南，並查看依目的分類的步驟。確認雙耳效果時請使用耳機。_

## 出現劈啪聲或斷音

1. 在「裝置」中確認麥克風和輸出的取樣率。
2. 把兩者設為相同的取樣率（支援：44100 / 48000 / 88200 / 96000 Hz）。取樣率可在 Windows 的音效設定或音訊介面的設定畫面中變更。
3. 先按「停止」，再重新按「開始」。
4. 仍然持續時，請開啟「防斷音模式」（延遲增加約 30 ms）。

使用音訊介面時，[DAW（VST 橋接）](../audio/vst-bridge)可能更穩定。

## 聽不到自己的聲音・沒有聲音

- 確認上方按鈕顯示為「停止」（正在執行）。
- 依序查看輸入電平表和輸出電平表。只有輸入在動時，請檢查輸出裝置和「聲音」分頁的輸出音量。
- 確認輸入和輸出裝置是你想用的裝置。重新連接裝置後，請按「重新偵測」。
- 確認上方的「靜音」沒有開啟，也檢查 Windows 一側的靜音和音量。
- 音訊路徑為「DAW（VST 橋接）」時，請檢查 DAW 的輸入輸出和監聽。

## 無法連接追蹤・點不變成藍色

- 確認「位置」分頁的操作模式為「自動追蹤」。
- 確認輸入來源顯示為「接收中」。
- 確認使用的軸指定了 `—` 以外的參數。
- 確認已指定的軸顯示為「已校準」。

## 聲音會動，但位置不自然

- 用虛擬形象平常的姿勢重新[校準](../tracking/calibration)。
- 檢查「移動範圍」中的「反轉」和「平滑」。
- 確認「繞著頭部轉動（推薦）」的開關符合你的意圖。
- 檢查「左右環繞」「上下環繞」「深度變化幅度」。

## 同一台電腦上的其他應用程式收不到 VMC 了

請在「連接的詳細設定」中啟用「轉送收到的資料（連接埠）」。詳情請參閱[追蹤輸入來源](../tracking/overview#vmc-forwarding)。

## 連動無法連線

低延遲通話請檢查 Steam、所有權、元件、邀請及空位。穩定通話若顯示伺服器未設定，需要支援該功能的發行版本。新方式需確認碼與方式一致，取消或中斷後重試。僅在舊版直連通話失敗時，可嘗試固定網路或 IPv6。

[連動通話](../collab/call#call-modes)

## 聲音重複・有回音

- 確認 OBS 沒有從兩個通道擷取同一聲音（[把聲音送進 OBS 和直播](../streaming/obs)）。
- 確認喇叭的聲音沒有回到麥克風。建議使用耳機。

## 仍無法解決時

在「關於」分頁中按「匯出診斷 ZIP」，確認內容後附在問題回報中。診斷 ZIP 不包含音訊、邀請碼或認證資訊。

## 聲音變悶或出現低沉轟鳴

檢查聲音頁面的「摀耳」，將兩側滑桿恢復到 0%。放開按住時捂耳的快速鍵或 Stream Deck 按鍵。若僅大音量峰值變小，檢查「安全限制器」作用指示。

## 找不到追蹤應用程式

在同一台 PC 啟動電腦版 VTube Studio，啟用 API 並允許外掛連線（預設 localhost:8001）。只有 iPhone 應用程式無法連線。在同一台 PC 啟動 nizima LIVE，於外掛管理員啟用 VOrbit ASMR（預設 localhost:22022）。連線期間每 3 秒重試一次。保持連線結束程式後，下次啟動會自動連線。

## 無法載入音源組合

停止所有播放中的音源，等待載入完成。檢查組合引用的音訊檔案是否已移動或刪除。
