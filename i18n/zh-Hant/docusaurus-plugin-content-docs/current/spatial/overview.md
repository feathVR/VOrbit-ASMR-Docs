# 音源的移動方式

VOrbit ASMR 可以讓聲音繞著聽者的頭部轉動，也可以在平面上移動。兩者都在「位置」分頁中設定。

## 繞著頭部轉動（推薦）

預設使用這種方式。勾選「繞著頭部轉動（推薦）」後，聲音不在平面上，而是在以頭部為中心的球面上移動。

- 左右和上下的數值會變成以聽者為中心的角度。轉動的角度由「移動範圍」中的「左右環繞」「上下環繞」決定。
- 距離由「基準距離」決定，左右或上下移動時不變。因此音量穩定，聲音會繞著耳邊轉動。
- 只有指定了深度軸時，聲音才會在「深度變化幅度」的範圍內相對基準距離靠近或遠離。

攝影機對深度的估計往往不可靠，因此適合只讓追蹤負責左右和上下，距離用「基準距離」來決定的用法。

## 平面移動

取消勾選「繞著頭部轉動（推薦）」後，左右和上下的數值會直接對應到以公尺為單位的位置。深度也會在設定範圍內前後移動。適合不想讓聲音轉動、只想直接移動位置的情況。

## 仿真人頭朝向

在「仿真人頭朝向」中選擇聽者朝向哪一邊。

- **正面**：聽者與虛擬形象面對面。
- **背面**：聲音從背後傳來。

「基準距離」是平常姿勢時到聲音的距離。

## 位置面板的看法

「位置」分頁中的兩個面板，左側表示左右和上下，右側表示左右和深度。紅點是聲音（追蹤中為藍色），帶編號的圓是在「音源」分頁中讀取的單聲道音源。

「顯示範圍」為「自動」時，會依使用的軸和設定，按聲音實際能到達的範圍決定面板的比例。設為「手動」後，可以自己決定從中心到邊緣的範圍。

## 在直播畫面中顯示仿真人頭麥克風 {#dummy-head-overlay}

啟用「在直播畫面中顯示仿真人頭麥克風」後，會在所連接應用程式（VTube Studio / nizima LIVE）的畫面中放置仿真人頭麥克風的圖片。

- 切換正面和背面時，圖片也會跟著替換。
- 位置和大小請在該應用程式中直接拖曳調整。
- 在 nizima LIVE 中圖片黏在虛擬形象上時，取消道具操作中的「跟隨模型」即可讓它停留在原處。
- 圖片位於「開啟圖片資料夾」所開啟的資料夾中，可以用相同檔名替換成自己畫的圖。
