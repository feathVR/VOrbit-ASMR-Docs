# 聲音設定（HRTF・房間殘響）

在「聲音」分頁中選擇聲音本身的聽感。

![「聲音」畫面](/img/screenshots/zh-Hant/sound-zh-Hant.png)

_目前應用程式畫面。可用功能依發行版本而定。_

## HRTF（頭部相關傳遞函數）

HRTF 是描述聲音如何因頭部和耳朵的形狀而變化的資料。每個人的聽感有差異，請選擇自己最容易分辨位置的一種。

| 選項 | 內容 |
| --- | --- |
| **Steam Audio 內建** | 預設。Steam Audio 內建的 HRTF |
| **Neumann KU100** | 用仿真人頭麥克風 KU100 測得的 HRTF |
| **KEMAR** | 用研究用仿真人頭 KEMAR 測得的 HRTF |

建議一邊用耳機把聲音向左右、前後移動，一邊切換比較，選擇位置最清楚、聽起來最自然的一種。

## 房間殘響

為聲音加上房間的反射。預設為「無殘響」。

- 無殘響
- 更衣室
- 浴室
- 錄音間
- 雜物較多的小房間
- 殘響室
- 音樂廳
- 隧道

## 輸出音量

VOrbit ASMR 輸出的全部聲音的音量。

## 空間化

取消勾選後，不做空間化，直接輸出麥克風的聲音。也可用來比較有無空間化的差別。

## 安全限制器 {#safety-limiter}

將人聲、音源與通話對方聲音的最終混音突發峰值限制在 −1 dBFS 以下。預設開啟，保持左右音量比例，並於作用時顯示衰減量。無論開關狀態，都會加入 5 ms 前瞻延遲。無法控制後續設備或直播軟體增加的音量。

## 摀耳 {#ear-cover}

在房間混響下方模擬用手捂住聽眾耳朵的聲音。低沉轟鳴及接觸、揭開聲伴隨人聲、音源 1–4、混響與通話對方聲音變悶。傳送給通話對方的聲音不受影響。

- 左耳、右耳或雙耳按鈕用於捂住，再按一次放開。每隻耳朵會回到滑桿最後設定的非零位置（初次為 100%）。雙耳都捂住時，雙耳按鈕同時放開；否則捂住尚未捂住的耳朵。
- 「左耳」與「右耳」滑桿設定手的位置（0–100%），移動速度也影響聲音。按兩下恢復至 0%。
- 「左右連動」預設開啟。移動任一滑桿，左右都變化相同的量並保持差值；到達端點的一側會停住。連動僅適用於滑桿。
- 「摀住時間」與「鬆開時間」決定按鈕操作時低音升起和消退的時間。「低鳴聲大小」「剝離聲大小」「使用精油音色」用於調整音量與質感。
- 快速鍵與 Stream Deck 支援按住時捂耳，放開後恢復按下前的狀態。

啟動時雙耳都處於開放狀態。連動、聲音調整與捂住的目標位置會儲存，目前捂耳程度不儲存。
