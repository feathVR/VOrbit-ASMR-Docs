# 音源・快速鍵・精簡檢視

## 音源（播放音訊檔案）

在「音源」分頁中，可以分別播放 4 個音訊檔案。可以把音效和環境音與聲音一起放進空間中。

![「音源」畫面](/img/screenshots/zh-Hant/playback-zh-Hant.png)

_目前應用程式畫面。可用功能依發行版本而定。_

- 按各欄位的「選擇檔案」，或把音訊檔案拖放到欄位上即可讀取。
- 支援 WAV / MP3 / M4A / AAC / FLAC / WMA（Windows 支援的轉碼器），每個檔案最長 10 分鐘。
- **單聲道**音源可以移動位置。它在「位置」分頁的面板上顯示為帶編號的圓，隨時可以拖曳。
- **立體聲**音源會保持原有的左右聲場播放，無法移動位置。
- 播放前需要先按上方的「開始」啟動音訊處理。
- 播放的聲音會混入與麥克風相同的輸出，連動通話中也會傳送給對方。音量在各欄位中調整。
- 點選或拖曳波形可以選擇播放位置。

## 播放、暫停與音量 {#playback-controls}

播放時按鈕變為「暫停」。暫停保留位置，再次播放從該處繼續。「停止」回到開頭。點選波形或拖曳後放開，播放時會跳轉，停止或暫停時僅選擇下次播放位置。立體聲波形上方是左 L，下方是右 R。高度依檔案內最大峰值縮放，不代表輸出音量。

音量以 dB 調整（−60 至 +20 dB；0 dB 為原始音量，−60 dB 為靜音）。每個音源的「殘響」決定是否加入房間混響。單聲道音源也可在音源頁面的正面與俯視面板拖曳。這些面板不顯示你的人聲，顯示範圍與位置頁面分別儲存。

## 預設與音源組合 {#source-sets}

從「預設」選擇內附聲音。Mosco 的《VR向けASMRループ音源集》第 1–3 集僅供在應用程式內播放，不可擷取作其他用途。關於頁面提供作者資訊與素材集連結。未包含預設包的版本不顯示此選單。

「音源組合」一起儲存音源 1–4 的聲音、音量、循環、位置與混響設定。

1. 停止所有播放中的音源，在「讀取組合」選擇內附或已登錄的組合。「從檔案讀取…」也可開啟 .vorbitset 檔案。
2. 調整後使用「儲存組合」。儲存的組合也會登錄供 Stream Deck 使用。
3. 「登錄現有組合…」登錄既有組合。「取消登錄」只移除登錄，不刪除原始組合與音訊檔案。

音源播放中不能載入組合。音訊檔案不會複製進組合，移動或刪除後可能無法使用。

## 快速鍵

在「快速鍵」分頁中，可以為應用程式的操作指定鍵盤快速鍵。操作其他應用程式時也有效。

![「快速鍵」畫面](/img/screenshots/zh-Hant/hotkeys-zh-Hant.png)

_目前應用程式畫面。可用功能依發行版本而定。_

1. 勾選「啟用快速鍵」。
2. 按要指定的操作所在列右側的按鍵欄。
3. 按下想用的按鍵再放開（也可與 Ctrl・Alt・Shift 組合）。

按 Esc 取消，按 × 解除指定。Windows 鍵、Esc、F12 等保留鍵無法使用。與其他應用程式衝突而無法註冊時，請換一個按鍵，然後按「重新檢查衝突」。

## 全部靜音 {#master-mute}

頂端喇叭按鈕停止人聲、音源、混響、對方聲音及傳送給對方的聲音。按鈕變紅，視窗標題顯示靜音。再次按下恢復。檔案仍在無聲播放。這與只關閉通話麥克風不同。啟動時解除靜音。

咳嗽等情況可給快速鍵或 Stream Deck 指派按住時靜音，也可指派捂耳操作。長按普通快速鍵不會重複操作。設定期間快速鍵暫停，取消或衝突會保留原指派。

## Stream Deck 與外部控制 {#stream-deck}

安裝內附 Stream Deck 外掛，將操作放到按鍵上，可控制全部靜音、捂耳、音源播放與音量、載入音源組合等。應用程式執行時自動連線。紅色連線圖示表示未連線，中斷時按下的操作不會排程補執行。

Stream Deck + 旋鈕可調整音源與輸出音量、捂耳程度。Neo 的 Infobar 用於狀態顯示，也附有 XL 初始配置。播放中不能載入音源組合。

自製工具可透過同一 PC 與 Windows 使用者的本機 WebSocket API 控制。內附離線說明書介紹連線資訊，並提供 PowerShell 7 的 control.ps1 範例。不接受瀏覽器連線。

## 精簡檢視與視窗置頂

按上方的「精簡檢視」，會切換成直播時不佔空間的小視窗。在小視窗中也可以進行開始、靜音、播放音源和連動通話等操作。按「回到完整檢視」恢復原狀。

勾選「視窗置頂」後，VOrbit ASMR 的視窗會一直顯示在其他視窗前面。
