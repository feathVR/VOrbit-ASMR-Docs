# 音源・快速鍵・精簡檢視

## 音源（播放音訊檔案）

在「音源」分頁中，可以分別播放 4 個音訊檔案。可以把音效和環境音與聲音一起放進空間中。

![「音源」畫面](/img/screenshots/zh-Hant/playback-zh-Hant.png)

_「音源」畫面。4 個欄位各讀取一個音訊檔案。_

- 按各欄位的「選擇檔案」，或把音訊檔案拖放到欄位上即可讀取。
- 支援 WAV / MP3 / M4A / AAC / FLAC / WMA（Windows 支援的轉碼器），每個檔案最長 10 分鐘。
- **單聲道**音源可以移動位置。它在「位置」分頁的面板上顯示為帶編號的圓，隨時可以拖曳。
- **立體聲**音源會保持原有的左右聲場播放，無法移動位置。
- 播放前需要先按上方的「開始」啟動音訊處理。
- 播放的聲音會混入與麥克風相同的輸出，連動通話中也會傳送給對方。音量在各欄位中調整。
- 點選或拖曳波形可以選擇播放位置。

## 快速鍵

在「快速鍵」分頁中，可以為應用程式的操作指定鍵盤快速鍵。操作其他應用程式時也有效。

![「快速鍵」畫面](/img/screenshots/zh-Hant/hotkeys-zh-Hant.png)

_「快速鍵」畫面。為每個操作指定按鍵。_

1. 勾選「啟用快速鍵」。
2. 按要指定的操作所在列右側的按鍵欄。
3. 按下想用的按鍵再放開（也可與 Ctrl・Alt・Shift 組合）。

按 Esc 取消，按 × 解除指定。Windows 鍵、Esc、F12 等保留鍵無法使用。與其他應用程式衝突而無法註冊時，請換一個按鍵，然後按「重新檢查衝突」。

## 精簡檢視與視窗置頂

按上方的「精簡檢視」，會切換成直播時不佔空間的小視窗。在小視窗中也可以進行開始、靜音、播放音源和連動通話等操作。按「回到完整檢視」恢復原狀。

勾選「視窗置頂」後，VOrbit ASMR 的視窗會一直顯示在其他視窗前面。
