# 校準

校準用來告訴 VOrbit ASMR 如何解讀追蹤應用程式傳來的數值。把平常的姿勢記錄為「中心」，並測量直播時身體會動到多遠（動作範圍）。

已指定的每個軸分別校準，設為 `—` 的軸一律視為位於中心。

## 步驟

<img src="/VOrbit-ASMR-Docs/img/calibration-zh-Hant.svg" alt="選擇左右軸、面向正面記錄中心、左右移動測量動作範圍、確認已校準的四步驟圖" width="1200" height="660" />

_可以對照圖片操作。[開啟圖片放大檢視](/img/calibration-zh-Hant.svg)。_

1. [連接追蹤](./overview)，並為左右軸指定參數。
2. 保持平常的姿勢和位置，按「記錄中心」。
3. 按「測量動作範圍」，沿使用的軸方向，比實際直播時稍大一點地移動。
4. 按「結束測量」，確認顯示從「未校準」變為「已校準」。
5. 左右移動，確認聲音在預期範圍內移動。

![校準一欄](/img/screenshots/zh-Hant/calibration-zh-Hant.png)

_「記錄中心」「測量動作範圍」「重設校準」，右側顯示校準狀態。_

## 調整動作

在「位置」分頁的「移動範圍」中調整。

- 方向相反時，勾選該軸的「反轉」。
- 細微抖動時，調高「平滑」。
- 聲音移動過多或不足時，調整「左右環繞」「上下環繞」「深度變化幅度」。

校準測量的是身體的動作（輸入），「移動範圍」決定聲音移動多遠（輸出）。重新校準不會改變「移動範圍」的設定。

## 需要重新校準的情況

校準依輸入來源和所選參數名稱的組合分別儲存。遇到以下情況時，請依新的輸入重新校準。

- 更換了使用的參數
- 改變了攝影機的位置
- 更換了模型或追蹤器

想用數值精細調整時，開啟「用數值調整校準值」，可直接輸入各軸的中心和單側幅度。
