# 發出第一個聲音

本頁帶你從安裝完成走到「聽到聲音在空間中移動」。一開始先不用追蹤，用手拖曳聲音來確認，比較容易找出卡在哪一步。

_先用 1〜3 確認聲音和位置的變化。只有需要自動追蹤時才繼續 4〜5。[開啟圖片放大檢視](/img/quick-start-zh-Hant.svg)。_

## 需要準備

- 要使用的麥克風，以及耳機或耳塞式耳機
- 需要自動移動時，準備支援的虛擬形象或追蹤應用程式（VTube Studio、nizima LIVE、VMC 傳送應用程式）

:::warning
為了正確確認空間音訊的位置，請使用耳機，而不是喇叭。
:::

## 跟著教學進行

第一次啟動時會開啟「裝置」畫面，並在視窗上方顯示「初始設定」的引導。引導共有 5 個步驟。

![初始設定的引導](/img/screenshots/zh-Hant/tutorial-zh-Hant.png)

_初始設定的引導，正在顯示第 1 步「選擇麥克風和輸出裝置」。_

1. 選擇麥克風和輸出裝置
2. 先聽聽聲音的移動
3. 連接追蹤
4. 記錄中心和動作範圍
5. 把聲音送進直播

按各步驟的「前往此步驟的畫面」，會切換到該設定所在的畫面，並標示出要操作的位置。完成步驟後引導上會出現完成標記，但不會自動進入下一步。確認沒問題後，請按「已確認，下一步」。

中途想停下時，請按「稍後（可從「使用方法」繼續）」。之後可以在「使用方法」分頁中按「開始教學」從頭再來。

## 步驟

### 1. 選擇麥克風和輸出裝置

開啟「裝置」分頁，確認「音訊路徑」為「一般」。在「輸入裝置（麥克風）」中選擇要用的麥克風，在「輸出裝置」中選擇連接耳機的裝置。不確定的話，保持「系統預設」即可。

要在 DAW 中使用時，請選擇「DAW（VST 橋接）」，然後依照 [VST 橋接的步驟](../audio/vst-bridge) 設定。

![「裝置」畫面](/img/screenshots/zh-Hant/device-zh-Hant.png)

_「裝置」畫面。選擇「一般」時，在這個畫面選擇麥克風和輸出裝置。_

### 2. 按「開始」並發出聲音

按上方的「開始」，對著麥克風拉長聲音發「啊——」。耳機裡聽到自己的聲音，上方的輸入和輸出電平表在動，就成功了。

### 3. 拖曳紅點移動聲音

在「位置」分頁中把「操作模式」設為「手動」。一邊拉長聲音，一邊抓住位置面板上的紅點（你的聲音）左右拖曳。耳機裡的聲音跟著移動，就代表 VOrbit ASMR 的基本體驗已經完成。

![設為「手動」的「位置」畫面](/img/screenshots/zh-Hant/position-manual-zh-Hant.png)

_左側面板表示左右和上下，右側面板表示左右和深度。紅點就是你的聲音。_

### 4. 自動移動（選用）

想讓虛擬形象的動作帶動聲音時，請[連接追蹤](../tracking/overview)，並[校準中心和動作範圍](../tracking/calibration)。

### 5. 把聲音送進直播

要直播時，請參閱[把聲音送進 OBS 和直播](../streaming/obs)。

:::tip 降噪是選用的
只在電腦風扇、冷氣等持續的環境噪音讓你在意時才開啟。預設關閉，開啟後延遲增加約 10 ms。詳情請參閱[降噪](../audio/noise-suppression)。
:::

## 不順利時

請在[常見問題](../troubleshooting/common-issues)中檢查斷音、音訊裝置和追蹤連線。
