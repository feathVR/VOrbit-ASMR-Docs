# 常見疑問

## 購買前可以了解操作方法嗎？

可以。本使用指南公開提供，購買前就能了解所需的應用程式、連線方式和設定流程。

## 如何變更顯示語言？

首次啟動時，應用程式會自動採用 Windows 的顯示語言；如果該語言不受支援，則使用英文。

如需變更，請開啟左側導覽列最下方的 **「關於」**，在 **「語言」** 下拉選單中選擇。變更會立即生效，並在下次啟動時保留。

可選的 8 種語言為：日本語 / English / 简体中文 / 繁體中文 / 한국어 / Русский / Español / Português (Brasil)。

## 一開始需要設定左右、上下、深度全部三個軸嗎？

不需要。建議先只用左右軸確認動作。上下和深度請在追蹤輸入來源能提供穩定數值時再加入。

## 未指定的軸會怎樣？

選擇 `—` 的軸視為位於中心。即使留有以前的校準值，也不會影響該軸的位置。

## 在哪裡可以找到 Stream Deck 外掛？

Stream Deck 外掛隨應用程式提供。安裝後將操作放到按鍵上。參閱 [Stream Deck 與外部控制](features/other#stream-deck)。

## 如何回報問題？

關於本指南內容的問題，可以在本站的 GitHub 儲存庫中回報。關於產品本體的支援窗口，請查看發佈時的說明。
