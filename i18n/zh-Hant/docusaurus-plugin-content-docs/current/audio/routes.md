# 選擇音訊路徑

VOrbit ASMR 可以依使用方式選擇音訊的通路。兩者沒有音質優劣之分，請選擇適合你平時直播和錄音環境的一種。在「裝置」分頁的「音訊路徑」中切換。

| 音訊路徑 | 適合的用法 | 輸入輸出的設定位置 |
| --- | --- | --- |
| **一般** | 只用 VOrbit ASMR 快速上手 | VOrbit ASMR 的「裝置」畫面 |
| **DAW（VST 橋接）** | 接入 DAW 的音軌或現有效果器鏈 | DAW／VST 主機 |

![「裝置」畫面的設定](/img/screenshots/zh-Hant/device-card-zh-Hant.png)

_選擇「一般」時的「裝置」畫面。依序是音訊路徑、降噪、輸入輸出裝置、防斷音和如何接入直播。_

## 選擇「一般」時

在「輸入裝置（麥克風）」中選擇麥克風，在「輸出裝置」中選擇耳機，然後按上方的「開始」。第一次確認時保持「系統預設」也可以。重新連接裝置後，請按「重新偵測」。

### 統一取樣率

畫面上會顯示麥克風和輸出的取樣率。請把兩者設為相同的值（支援：44100 / 48000 / 88200 / 96000 Hz）。取樣率可在 Windows 的音效設定或音訊介面的設定畫面中變更。變更後，先按「停止」，再重新按「開始」。

### 防斷音模式

持續出現劈啪聲或斷音時，請開啟「防斷音模式」。它會讓麥克風與輸出分開運作，並在中間保留餘裕，因此延遲增加約 30 ms。麥克風和輸出是不同裝置時也能保持穩定。

## 選擇「DAW（VST 橋接）」時

VOrbit ASMR 不會自己開啟音訊裝置。它從插在 DAW 中的 **VOrbit Bridge** 接收音訊，把空間化後的音訊送回同一位置。裝置、取樣率和緩衝區都在 DAW 中設定。

使用音訊介面時，這種方式可能更穩定。請繼續閱讀[使用 VST 橋接](./vst-bridge)。

:::note
「開始」期間無法變更音訊路徑、輸入輸出裝置、降噪和防斷音模式。請先按「停止」再變更。
:::
