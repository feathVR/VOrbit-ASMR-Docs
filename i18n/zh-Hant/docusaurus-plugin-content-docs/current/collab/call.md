# 連動通話

向遠端夥伴傳送立體聲 ASMR。連線步驟取決於通話方式及版本。

![「連動」畫面](/img/screenshots/zh-Hant/collab-zh-Hant.png)

_目前應用程式畫面。可用功能依發行版本而定。_

## 通話方式與版本 {#call-modes}

目前原始碼的連動頁面包含「低延遲通話」與「穩定通話」，皆使用 48 kHz 立體聲 Opus。新方式仍在開發，尚未完成公開發行整合及跨 PC 實際通話驗證。可用方式取決於發行版本。

| 方式 | 條件與行為 |
| --- | --- |
| **低延遲通話** | 需要啟動 Steam、配套元件及所有權。含自己最多 4 人。主持人離開時房間結束。 |
| **穩定通話** | 經由發行方設定的伺服器進行立體聲通話，人數上限依伺服器而定。目前接收端約緩衝 200 ms 後播放，延遲較大。未設定伺服器的版本無法使用。 |

### 新方式的連線步驟

1. 所有人選擇輸入及輸出並啟動音訊處理。使用 VST 橋接時先連接 DAW。
2. 選擇相同通話方式。建立邀請、連線中或通話中不能切換。
3. 主持人產生邀請碼，僅私下傳給參與者。參與者貼上後連線。新方式不需回傳回應碼。
4. 用「複製房間邀請碼」邀請更多人。中斷連線即可退出。斷線後尚不支援自動恢復。

免費版不能建立房間或發碼，只能加入相容的穩定通話房間，不能加入產品版低延遲房間。免費版發行及參與資格設定也屬公開前待完成事項。兩種方式的碼不相容。延遲或遺失率顯示「—」表示未測量，不是零。

## 舊版一對一通話 {#legacy-call}

以下適用於需要交換邀請碼及回應碼的舊版，與新方式步驟不同。

![連動通話的流程](/img/screenshots/zh-Hant/help-collab-zh-Hant.png)

_舊版邀請與回應碼交換步驟。新方式見上文。_

1. **雙方都先按「開始」**
   雙方先選擇麥克風和輸出裝置，然後按上方的「開始」。建議使用耳機。
2. **傳送邀請碼（邀請方）**
   在「連動」分頁中按「建立邀請碼」，把複製好的代碼透過 Discord 私訊等方式只傳給對方。
3. **貼上代碼並回傳回應（被邀請方）**
   在「貼上對方傳來的代碼」中貼上收到的代碼，然後按「連接」。回應碼會自動複製，請把它回傳給邀請方。
4. **貼上回應碼（邀請方）**
   貼上收到的回應碼並按「連接」。雙方都顯示「通話中」即完成。

:::warning 邀請碼等同備用鑰匙
知道邀請碼的人就能加入通話。請不要貼到公開頻道。連線失敗的代碼不要重複使用，請重新建立。
:::

## 通話中可以做的事

- 調整對方音量和靜音
- 查看延遲和封包遺失率
- 按「中斷」結束通話

在「音源」分頁中播放的聲音，通話時也會傳送給對方。

## 使用實體雙耳麥克風時

如果你已經有雙耳麥克風或立體聲錄音環境，請勾選「使用實體雙耳麥克風（不做空間化，原樣傳送）」。麥克風的左右聲道會原樣傳送給對方。使用一般麥克風時請不要勾選。

「開始」期間無法變更此設定。

## 無法連線時 {#cannot-connect}

低延遲通話請檢查 Steam、所有權、元件、邀請及空位。穩定通話若顯示伺服器未設定，需要支援該功能的發行版本。新方式需確認碼與方式一致，取消或中斷後重試。僅在舊版直連通話失敗時，可嘗試固定網路或 IPv6。
