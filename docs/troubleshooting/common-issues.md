# よくある問題

アプリ内の「使い方」タブの「うまく動かないとき」にも、同じ確認の手順があります。

![「使い方」画面](/img/screenshots/ja/help-ja.png)

_「使い方」タブ。チュートリアルの再開、この操作ガイドを開くボタン、目的別の手順があります。バイノーラルの確認にはヘッドホンまたはイヤホンを使ってください。_

## プツプツ・音切れする

1. 「デバイス」で、マイクと出力の周波数を確認します。
2. 両方を同じ周波数（対応：44100 / 48000 / 88200 / 96000 Hz）にそろえます。周波数はWindowsのサウンド設定か、オーディオインターフェースの設定画面で変えられます。
3. 変えたら「停止」してから「開始」し直します。
4. それでも続くときは「音切れ対策モード」をオンにします（遅延が約30 ms増えます）。

オーディオインターフェースを使っている場合は、[DAW（VSTブリッジ）](../audio/vst-bridge)の方が安定することがあります。

## 自分の声が返ってこない・音が出ない

- 上部のボタンが「停止」になっているか（動作中か）を確認します。
- 入力メーター、出力メーターの順に確認します。入力だけ動くなら、出力先と「音」タブの出力音量を確認します。
- 入力・出力デバイスが意図した機器になっているか確認します。機器をつなぎ直したときは「再検出」を押します。
- 上部の「ミュート」がオンになっていないか、Windows側のミュートと音量も確認します。
- 音声経路を「DAW（VSTブリッジ）」にしている場合は、DAW側の入出力とモニターを確認します。

## トラッキングにつながらない・点が青にならない

- 「位置」タブの操作モードが「オート追従」になっているか確認します。
- 入力ソースの表示が「受信中」になっているか確認します。
- 使う軸に、`—`以外のパラメーターが割り当てられているか確認します。
- 割り当てた軸が「較正済み」になっているか確認します。

## 声は動くが位置が不自然

- アバターの普段の姿勢で、[較正](../tracking/calibration)をやり直します。
- 「動きの範囲」の「反転」と「スムージング」を確認します。
- 「頭のまわりを回る（おすすめ）」のオン・オフが意図どおりか確認します。
- 「左右の回り込み」「上下の回り込み」「奥行きの変化幅」を確認します。

## 同じPCの別アプリでVMCを受信できなくなった

「接続の詳細設定」で「受け取ったデータを転送する（ポート）」を有効にしてください。詳しくは[トラッキングソース](../tracking/overview#vmc-forwarding)を参照してください。

## コラボがつながらない

二人とも「開始」しているか確認し、新しい招待コードで最初からやり直します。別の固定回線や、IPv6の使える回線も試してください。詳しくは[コラボ通話](../collab/call#cannot-connect)を参照してください。

## 音が二重になる・響く

- OBSで同じ音を二系統から取り込んでいないか確認します（[OBS・配信へ音を載せる](../streaming/obs)）。
- スピーカーの音がマイクへ戻っていないか確認します。ヘッドホンの使用をおすすめします。

## 解決しないとき

「アプリについて」タブの「診断ZIPを書き出す」で診断情報を書き出し、中身を確認してから不具合報告に添付してください。音声・招待コード・認証情報は診断ZIPに含まれません。
