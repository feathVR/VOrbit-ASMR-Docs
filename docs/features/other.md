# 音源・ホットキー・縮小表示

## 音源（音声ファイルの再生）

「音源」タブでは、4つの音声ファイルを個別に再生できます。効果音や環境音を、声と一緒に空間の中へ置けます。

![「音源」画面](/img/screenshots/ja/playback-ja.png)

_「音源」画面。4つの枠に1つずつ音声ファイルを読み込みます。_

- 各枠の「ファイルを選択」を押すか、音声ファイルを枠へドラッグ＆ドロップして読み込みます。
- 対応形式はWAV / MP3 / M4A / AAC / FLAC / WMA（Windowsの対応コーデック）で、1ファイル10分までです。
- **モノラル**の音源は位置を動かせます。「位置」タブのパッドに番号の付いた丸で表示され、いつでもドラッグできます。
- **ステレオ**の音源は、元の左右の広がりを保って再生します。位置は動かせません。
- 再生するには、上部の「開始」で音声の処理を動かしておく必要があります。
- 再生音はマイクと同じ出力先に混ざり、コラボ通話中は相手にも送られます。音量は各枠で調整します。
- 波形をクリック・ドラッグすると、再生位置を選べます。

## ホットキー

「ホットキー」タブでは、キーボードからアプリの操作を呼び出せるように割り当てます。ほかのアプリを操作している間も有効です。

![「ホットキー」画面](/img/screenshots/ja/hotkeys-ja.png)

_「ホットキー」画面。操作ごとにキーを割り当てます。_

1. 「ホットキーを有効にする」にチェックを入れます。
2. 割り当てたい操作の行の右にあるキー欄を押します。
3. 使いたいキーを押して離します（Ctrl・Alt・Shiftとの組み合わせも使えます）。

Escで取り消し、×で割り当てを解除します。Windowsキー、Esc、F12などの予約キーは使えません。ほかのアプリと重なって登録できない場合は、別のキーを選んでから「競合を再確認」を押してください。

## 縮小表示と常に手前

上部の「縮小表示」を押すと、配信中に場所を取らない小さな画面に切り替わります。開始・ミュート・音源の再生・コラボ通話などを、小さな画面のまま操作できます。「通常表示に戻す」で元に戻ります。

「常に手前」にチェックを入れると、VOrbit ASMRのウィンドウがほかのウィンドウより前に表示され続けます。
