# 音源・ホットキー・縮小表示

## 音源（音声ファイルの再生）

「音源」タブでは、4つの音声ファイルを個別に再生できます。効果音や環境音を、声と一緒に空間の中へ置けます。

![「音源」画面](/img/screenshots/ja/playback-ja.png)

_現行アプリの画面。配布版によって利用できる機能が異なります。_

- 各枠の「ファイルを選択」を押すか、音声ファイルを枠へドラッグ＆ドロップして読み込みます。
- 対応形式はWAV / MP3 / M4A / AAC / FLAC / WMA（Windowsの対応コーデック）で、1ファイル10分までです。
- **モノラル**の音源は位置を動かせます。「位置」タブのパッドに番号の付いた丸で表示され、いつでもドラッグできます。
- **ステレオ**の音源は、元の左右の広がりを保って再生します。位置は動かせません。
- 再生するには、上部の「開始」で音声の処理を動かしておく必要があります。
- 再生音はマイクと同じ出力先に混ざり、コラボ通話中は相手にも送られます。音量は各枠で調整します。
- 波形をクリック・ドラッグすると、再生位置を選べます。

## 再生・一時停止・音量 {#playback-controls}

再生中のボタンは「一時停止」になります。一時停止は位置を保ち、再生でその位置から再開します。「停止」は先頭へ戻します。波形をクリックするかドラッグして離すと、再生中はその位置へ移り、停止・一時停止中は次の再生位置だけを選びます。ステレオ波形は上が左 L、下が右 R です。高さはファイル内の最大音に合わせた表示で、出力音量そのものではありません。

音量は dB で調整します（−60〜+20 dB、0 dB が元の音量、−60 dB は無音）。各音源の「響き」で部屋の響きを加えるか選べます。モノラル音源は「音源」画面の正面・上面パッドでも動かせます。このパッドには自分の声を表示せず、表示範囲も「位置」画面とは別に保存します。

## プリセットと音源セット {#source-sets}

「プリセット」から同梱の音を選べます。Mosco さんの「VR向けASMRループ音源集」第 1〜3 集をアプリ内で再生するためのもので、取り出して別用途に使うことはできません。作者と素材集の案内は「アプリについて」にあります。プリセットのない配布版ではこのメニューは出ません。

「音源セット」は音源 1〜4 の音・音量・ループ・位置・反響の設定をまとめます。

1. 再生中の音源をすべて止め、「セットを読み込む」から同梱または登録済みのセットを選びます。「ファイルから読み込む…」で .vorbitset ファイルも読み込めます。
2. 組み合わせを変えたら「セットを保存」で保存します。保存したセットは Stream Deck 用にも登録されます。
3. 「既存のセットを登録…」で既存のセットを登録できます。「登録を解除」は登録だけを外し、元のセット・音声ファイルは削除しません。

読み込みは再生中にできません。音声ファイル自体はセットへコピーされないため、移動・削除すると利用できなくなることがあります。

## ホットキー

「ホットキー」タブでは、キーボードからアプリの操作を呼び出せるように割り当てます。ほかのアプリを操作している間も有効です。

![「ホットキー」画面](/img/screenshots/ja/hotkeys-ja.png)

_現行アプリの画面。配布版によって利用できる機能が異なります。_

1. 「ホットキーを有効にする」にチェックを入れます。
2. 割り当てたい操作の行の右にあるキー欄を押します。
3. 使いたいキーを押して離します（Ctrl・Alt・Shiftとの組み合わせも使えます）。

Escで取り消し、×で割り当てを解除します。Windowsキー、Esc、F12などの予約キーは使えません。ほかのアプリと重なって登録できない場合は、別のキーを選んでから「競合を再確認」を押してください。

## 全体ミュート {#master-mute}

上部のスピーカーボタンは、自分の声・音源・残響・通話相手の声と、通話相手へ送る音をすべて止めます。ミュート中はボタンが赤くなり、題名にも表示されます。もう一度押すと戻ります。ファイル再生は無音のまま進みます。通話の自分のマイクだけのミュートとは別です。起動時は解除されます。

咳などの間だけ止める場合は、ホットキーや Stream Deck に押している間だけのミュートを割り当てます。耳ふさぎの操作も割り当てられます。キーを長押ししても操作は繰り返しません。登録中はホットキーを一時停止し、取消・競合時は元の割り当てを保ちます。

## Stream Deck と外部操作 {#stream-deck}

同梱の Stream Deck プラグインをインストールし、アクションをキーへ置きます。全体ミュート・耳ふさぎ・音源の再生や音量・音源セットの読み込みなどを操作できます。アプリを起動すると自動接続します。赤い接続アイコンは未接続で、切断中に押した操作は後から実行されません。

Stream Deck + のダイヤルで音源・出力の音量や耳のふさぎ具合を調整できます。Neo の Infobar は状態表示用です。XL 用の初期配置プロフィールも同梱しています。音源セットは再生中に読み込めません。

自作ツールからも同じ PC・Windows ユーザーのローカル WebSocket API を使えます。同梱のオフライン説明書に接続情報と PowerShell 7 用の control.ps1 実行例があります。ブラウザーからの接続は受け付けません。

## 縮小表示と常に手前

上部の「縮小表示」を押すと、配信中に場所を取らない小さな画面に切り替わります。開始・ミュート・音源の再生・コラボ通話などを、小さな画面のまま操作できます。「通常表示に戻す」で元に戻ります。

「常に手前」にチェックを入れると、VOrbit ASMRのウィンドウがほかのウィンドウより前に表示され続けます。
