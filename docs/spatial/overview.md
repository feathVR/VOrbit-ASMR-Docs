# 音源の動き方

VOrbit ASMRでは、声をリスナーの頭のまわりに回り込ませる方式と、平面上で移動させる方式を選べます。どちらも「位置」タブで設定します。

_左右だけを動かした場合の概念図です。[画像を開いて拡大](/img/spatial-mapping-ja.svg)できます。_

## 頭のまわりを回る（おすすめ）

既定ではこちらを使います。「頭のまわりを回る（おすすめ）」にチェックが入っていると、声は平面ではなく頭を中心とした球面上を動きます。

- 左右と上下の値は、リスナーを中心とした角度になります。回り込む角度は「動きの範囲」の「左右の回り込み」「上下の回り込み」で決まります。
- 距離は「基準距離」で決まり、左右や上下へ動いても変わりません。そのため音量が安定し、耳もとを回り込む動きになります。
- 奥行きの軸を割り当てた場合だけ、「奥行きの変化幅」の分だけ基準距離から近づいたり遠ざかったりします。

Webカメラの奥行きの推定は当てにならないことが多いため、左右と上下だけをトラッキングに任せ、距離は「基準距離」で決める使い方に向いています。

## 平面上の配置

「頭のまわりを回る（おすすめ）」のチェックを外すと、左右と上下の値をメートル単位の位置へ直接割り当てます。奥行きも設定範囲に応じて前後へ移動します。声を回り込ませず、位置を直接動かしたい場合に使います。

## ダミーヘッドの向き

「ダミーヘッドの向き」で、聴く人がどちらを向いているかを選びます。

- **正面**：聴く人とアバターが向かい合います。
- **背面**：声が後ろから聞こえます。

「基準距離」は、普段の姿勢のときの声までの距離です。

## 位置パッドの見方

「位置」タブの2つのパッドは、左が左右と上下、右が左右と奥行きを表します。赤い点が声（トラッキング中は青）、番号の付いた丸が「音源」タブで読み込んだモノラル音源です。

「表示範囲」の「自動」は、使っている軸と設定から、声が実際に届く範囲に合わせてパッドの縮尺を決めます。「手動」にすると、中心から端までの範囲を自分で決められます。

## 配信画面にダミーヘッドマイクを表示する

「配信画面にダミーヘッドマイクを表示する」を有効にすると、接続先のアプリ（VTube Studio / nizima LIVE）の画面にダミーヘッドマイクの画像を置きます。

- 正面と背面の切り替えに合わせて、画像も差し替わります。
- 位置や大きさは、そのアプリ上で直接ドラッグして調整します。
- nizima LIVEでアバターに貼り付いてしまう場合は、アイテム操作の「モデルに追従」のチェックを外すと、その場に留まります。
- 画像は「画像のフォルダを開く」で開くフォルダーにあり、同じファイル名で自作の絵に差し替えられます。
