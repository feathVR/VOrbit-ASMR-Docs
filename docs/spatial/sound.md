# 音の設定（HRTF・部屋の響き）

「音」タブでは、声の聞こえ方そのものを選びます。

![「音」画面](/img/screenshots/ja/sound-ja.png)

_現行アプリの画面。配布版によって利用できる機能が異なります。_

## HRTF（頭部伝達関数）

HRTFは、音が頭や耳の形によってどう変わるかを表すデータです。聞こえ方には個人差があるため、自分にとって位置が分かりやすいものを選んでください。

| 選択肢 | 内容 |
| --- | --- |
| **Steam Audio 内蔵** | 既定。Steam Audioに組み込まれたHRTF |
| **Neumann KU100** | ダミーヘッドマイク KU100 で測定したHRTF |
| **KEMAR** | 研究用のダミーヘッド KEMAR で測定したHRTF |

ヘッドホンで声を左右や前後へ動かしながら切り替え、位置が分かりやすく、不自然に聞こえないものを選ぶのがおすすめです。

## 部屋の響き

声に部屋の反響を加えます。既定は「反響なし」です。

- 反響なし
- ロッカールーム
- お風呂場
- 録音ブース
- 雑多な6畳間
- 残響室
- コンサートホール
- トンネル

## 出力音量

VOrbit ASMRから出る音全体の音量です。

## 空間化

チェックを外すと、空間化をせず、マイクの音をそのまま出力します。空間化の有無を聴き比べるときにも使えます。

## 安全リミッター {#safety-limiter}

声・音源・通話相手の声を合わせた最終出力の急な大音量を −1 dBFS 以下へ抑えます。既定はオンです。左右の音量比を保って動作し、作動中は抑えた量を表示します。オン・オフにかかわらず 5 ms の先読み遅延が加わります。後段の機器や配信ソフトで加えた音量は制御できません。

## 耳ふさぎ {#ear-cover}

「部屋の響き」の下の欄で、リスナーの耳を手でふさいだ音を出します。低いゴー音と、手が当たる・はがれる音が鳴り、声・音源 1〜4・部屋の響き・通話相手の声がこもります。通話相手へ送る自分の音にはかかりません。

- ボタンで左耳・右耳・両耳をふさぎ、もう一度押すと離します。最後にスライダーで決めた 0 でない位置までふさぎます（初回は 100 %）。両耳のボタンは、両耳ともふさいでいれば両方を離し、それ以外は開いている耳をふさぎます。
- 「左耳」「右耳」のスライダーは手の位置（0〜100 %）です。動かす速さでも音が変わります。ダブルクリックで 0 % に戻します。
- 「左右連動」は既定でオンです。どちらを動かしても両方が同じ量だけ動き、左右の差を保ちます。端に着いた耳はそこで止まります。連動はスライダーだけに適用されます。
- 「ふさぐ時間」「離す時間」は、ボタン操作で低音が立ち上がる・消える時間です。「ゴー音の大きさ」「はがれる音の大きさ」で音量を、「オイルを使った音にする」で質感を調整します。
- ホットキーや Stream Deck では、押している間だけふさぐ操作も使えます。離すと押す前の状態へ戻ります。

起動時は両耳とも開いた状態です。連動・音の調整・閉じ先は保存されますが、いまのふさぎ具合は保存されません。
