# コラボ通話

離れた相手とステレオ音声で ASMR を届ける機能です。通話方式と配布版によって接続手順が異なります。

![「コラボ」画面](/img/screenshots/ja/collab-ja.png)

_現行アプリの画面。配布版によって利用できる機能が異なります。_

## 通話方式と対応版 {#call-modes}

現行ソースの「コラボ」画面には「低遅延通話」と「安定通話」があります。両方とも 48 kHz・ステレオの Opus 音声です。新しい方式は開発中で、公開版への組み込み・別 PC 間の実通話検証はまだ完了していません。利用できる方式は配布版によります。

| 方式 | 利用条件と動作 |
| --- | --- |
| **低遅延通話** | Steam を起動し、対応する連携部品と所有権が必要。自分を含め最大 4 人。主催者が退出すると部屋を終了します。 |
| **安定通話** | 配布側が用意するサーバーへ接続するステレオ通話。人数上限はサーバーによります。現在の実装は受信側に約 200 ms ためてから再生するため、遅延が増えます。サーバー未設定の版では使えません。 |

### 新しい方式でつなぐ手順

1. 全員が入力と出力を選び、「開始」を押します。VST ブリッジでは先に DAW と接続します。
2. 同じ通話方式を選びます。招待の作成・接続・通話中は方式を変更できません。
3. 主催者が招待コードを作り、参加者だけに送ります。参加者は届いたコードを貼り付けて接続します。新方式では応答コードの送り返しは不要です。
4. 追加の参加者には「部屋の招待コードをコピー」でコードを共有できます。通話を終えるときは切断します。途切れた接続を自動で復旧する機能はまだありません。

無料版は部屋の作成・コード発行ができず、対応する安定通話の部屋への参加のみです。無料版から製品版の低遅延通話には参加できません。無料版の配布と参加資格の設定も公開前の準備事項です。2 方式のコードは互換性がありません。遅延・ロス率が「—」の場合は未計測で、ゼロという意味ではありません。

## 従来版の 1 対 1 通話 {#legacy-call}

以下は招待コードと応答コードを交換する従来版の手順です。新方式の手順とは異なります。

![コラボ通話の流れ](/img/screenshots/ja/help-collab-ja.png)

_従来版の招待・応答コードの交換手順です。新方式は上の説明を参照してください。_

1. **二人とも「開始」しておく**
   二人とも先にマイクと出力先を選び、上部の「開始」を押します。ヘッドホンを推奨します。
2. **招待コードを送る（招待する側）**
   「コラボ」タブで「招待コードを作る」を押し、コピーされたコードをDiscordのDMなどで相手だけに送ります。
3. **コードを貼って応答を返す（招待された側）**
   「相手から届いたコードを貼る」に届いたコードを貼って「接続」を押します。応答コードが自動でコピーされるので、招待した側へ貼り返します。
4. **応答コードを貼る（招待する側）**
   届いた応答コードを貼って「接続」を押します。両方に「通話中」が表示されれば完了です。

:::warning 招待コードは合鍵です
招待コードを知っている人は通話に入れます。公開チャンネルへ貼らないでください。うまくつながらなかったコードは使い回さず、新しく作り直してください。
:::

## 通話中にできること

- 相手の音量の調整とミュート
- 遅延とロス率の確認
- 「切断」で通話を終える

「音源」タブで再生した音も、通話中は相手に送られます。

## 実機のバイノーラルマイクを使う場合

すでにバイノーラルマイクやステレオの収録環境を持っている場合は、「実機バイノーラルマイクを使う（空間化せずそのまま送る）」にチェックを入れます。マイクの左右をそのまま相手に送ります。通常のマイクを使う場合は、チェックを入れないでください。

この設定は「開始」している間は変更できません。

## つながらないとき {#cannot-connect}

低遅延通話は Steam の起動・所有権・連携部品・招待・空席を確認します。安定通話でサーバー未設定と出る場合は、対応する配布版が必要です。新方式では方式とコードの組み合わせを確認し、接続中止または切断後にやり直します。従来の直結通話だけでつながらない場合は、どちらかが固定回線や IPv6 の使える回線を試してください。
