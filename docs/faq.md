# よくある質問

## 購入前でも操作方法を確認できますか？

はい。この操作ガイドは一般公開されており、必要なアプリ、接続方式、設定の流れを購入前に確認できます。

## 最初からX・Y・Zのすべてを設定する必要がありますか？

いいえ。まずX軸だけで左右の動きを確認することをおすすめします。Y軸とZ軸は、使用するトラッキングソースで安定した値を取得できる場合に追加してください。

## 未割り当ての軸はどうなりますか？

`—`を選択した軸は中央として扱われます。以前のキャリブレーション値が残っていても、その軸の位置には影響しません。

## Stream Deckプラグインはどこで確認できますか？

Stream Deckプラグインは、本体およびこの操作ガイドとは別の公開プロジェクトとして案内する予定です。公開後、このページからリンクします。

## 問題を報告するにはどうすればよいですか？

操作ガイドの記載に関する問題は、このサイトのGitHubリポジトリで報告できます。製品本体のサポート窓口は、配布時の案内を確認してください。
