# トラッキングソース

VOrbit ASMRは複数のトラッキング方式に対応しています。接続後、各アプリから利用可能なパラメーターを取得し、左右・上下・奥行きの軸へ個別に割り当てられます。

## 対応ソース

| ソース | 接続方式 | 最初に割り当てられる左右の軸 |
| --- | --- | --- |
| VTube Studio | PC API WebSocket | `FacePositionX` |
| VMC | OSC/UDP（既定の待ち受けポート 39539） | `Head.RotZ` |
| nizima LIVE | Plugin WebSocket | `Cubism.ParamAngleX` |

初めて接続したときは、左右の軸だけが割り当てられ、上下と奥行きは`—`（使わない）になっています。ソースが提供する値に応じて、上下や奥行きにも別のパラメーターを割り当てられます。

## 接続する

1. 先にトラッキング側のアプリとモデルを起動します。
2. 「位置」タブの「操作モード」を「オート追従」にします。
3. 「入力ソース」でアプリを選び、「接続」を押します。
4. 表示が「受信中」になれば接続できています。パッドの声の点が赤から青に変わり、ドラッグでは動かなくなります（番号の付いた丸の音源は引き続き動かせます）。

_「オート追従」で入力ソースを選び、「接続」を押します。_

## アプリ側で接続を許可する

- **VTube Studio**：PC版でAPIを有効にし、初回に表示されるプラグインの許可を承認します。
- **VMC**：送信側のアプリでVMC送信を有効にします。既定の待ち受けはUDP 39539です。ポートは「接続の詳細設定」で変えられます。
- **nizima LIVE**：初回のプラグイン接続を許可します。

## 使うパラメーターを選ぶ

接続すると「使用するパラメータ」が表示され、左右・上下・奥行きの軸ごとにパラメーターを選べます。

- 最初は左右だけがおすすめです。`—`にした軸は動きません。
- モデルの首振りに合わせるならAngle系（例：`ParamAngleX`）、画面内の移動に合わせるならPosition系（例：`FacePositionX`）を目安にします。
- カメラを使わずマウスで動かす場合は、VTube Studioの`MousePositionX` / `MousePositionY`を選べます。
- 上下や奥行きは、姿勢やカメラ距離の揺れが音に出やすいため、入力が安定している場合に追加してください。

パラメーターを変えたら、[較正](./calibration)をやり直してください。

## VMCで最初に試す設定

VMCでは送信アプリやモデルによって、使いやすいパラメーターが異なります。左右の軸には初期値の`Head.RotZ`（頭の傾き）が割り当てられます。動きが小さい、または動かない場合は`Hips.PosX`を試してください。

どちらの場合も、最初は左右だけに割り当て、上下と奥行きは`—`のままにします。
### iFacialMocapとWarudoの設定例

| 項目 | 設定 |
| --- | --- |
| キャプチャー方法・カメラ | iFacialMocap |
| VOrbit ASMR側の接続方法 | WarudoからVMCプロトコルで送信 |
| 左右 | `Head.RotZ` |
| 上下 | `—` |
| 奥行き | `—` |

Warudo側でVMC送信を有効にし、VOrbit ASMRでは入力ソースとして「VMC Protocol」を選んで接続します。

## ほかのアプリでもVMCを受け取る

VOrbit ASMRがVMCのデータを受け取ると、同じポートでは別のアプリが受け取れなくなります。同じPCの別のアプリでも使う場合は、「接続の詳細設定」の「受け取ったデータを転送する（ポート）」を有効にし、転送先のポートをそのアプリに合わせてください。
