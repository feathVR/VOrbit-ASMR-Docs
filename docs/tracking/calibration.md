# 較正（キャリブレーション）

較正は、トラッキングアプリが送る値を、VOrbit ASMR内の声の動きとして解釈するための設定です。普段の姿勢を「中央」として記録し、配信中に体がどこまで動くか（可動範囲）を測ります。

割り当てた軸はそれぞれ個別に較正され、`—`にした軸は常に中央として扱われます。

## 手順

<img src="/VOrbit-ASMR-Docs/img/calibration-ja.svg" alt="左右の軸を選び、正面で中央を記録し、左右へ動きながら可動範囲を測定し、較正済みを確認する4段階の図" width="1200" height="660" />

_図を見ながら操作できます。[画像を開いて拡大](/img/calibration-ja.svg)できます。_

1. [トラッキングに接続](./overview)し、左右の軸にパラメーターを割り当てます。
2. 普段の姿勢と位置のまま「中央を記録」を押します。
3. 「可動範囲を測定」を押し、使用する軸の方向へ、実際の配信中より少し大きめに動きます。
4. 「測定を終了」を押し、表示が「未較正」から「較正済み」になったことを確認します。
5. 左右へ動き、想定した範囲で声が移動するか確認します。

![較正の欄](/img/screenshots/ja/calibration-ja.png)

_「中央を記録」「可動範囲を測定」「較正をリセット」と、右端に較正の状態が表示されます。_

## 動きを整える

「位置」タブの「動きの範囲」で調整します。

- 動きが逆なら、その軸の「反転」にチェックを入れます。
- 細かく震えるなら「スムージング」を上げます。
- 声が動き過ぎる、または足りないときは「左右の回り込み」「上下の回り込み」「奥行きの変化幅」を調整します。

較正で測るのは体の動き（入力）で、「動きの範囲」は声がどこまで動くか（出力）です。較正をやり直しても「動きの範囲」の設定は変わりません。

## 較正をやり直すとき

較正は、入力ソースと選んだパラメーター名の組み合わせごとに保存されます。次のようなときは、その入力に合わせて較正し直してください。

- 使うパラメーターを変えたとき
- カメラの位置を変えたとき
- モデルやトラッカーを変えたとき

数値で細かく直したい場合は、「較正値を数値で調整」を開くと、軸ごとの中心と可動幅を直接入力できます。
