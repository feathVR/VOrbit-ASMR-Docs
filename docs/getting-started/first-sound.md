# 最初の音を出す

インストール後、声が空間音響として聞こえるところまでを設定します。最初はトラッキングを使わず、手で声を動かして確かめると、つまずいた場所が分かりやすくなります。

## 一枚でわかる、かんたん設定

<img src="/VOrbit-ASMR-Docs/img/quick-start-ja.svg" alt="VOrbit ASMRの音出しと自動追従を5段階で説明する、かんたん設定シート" width="1200" height="1600" />

_まず1〜3で音と位置の変化を確認します。自動追従を使う場合だけ4〜5へ進んでください。[画像を開いて拡大](/img/quick-start-ja.svg)できます。_

## 用意するもの

- 使用するマイクとヘッドホンまたはイヤホン
- 自動で動かす場合は、対応するアバター・トラッキングアプリ（VTube Studio、nizima LIVE、VMC送信アプリ）

:::warning
空間音響の位置を正しく確認するため、スピーカーではなくヘッドホンまたはイヤホンを使ってください。
:::

## チュートリアルに沿って進める

初めて起動すると「デバイス」画面が開き、画面の上部に「初回設定」の案内が表示されます。案内は次の5つの手順です。

![初回設定の案内](/img/screenshots/ja/tutorial-ja.png)

_初回設定の案内。1つ目の手順「マイクと出力先を選ぶ」を表示しているところです。_


1. マイクと出力先を選ぶ
2. まず音の動きを聴く
3. トラッキングを接続する
4. 中央と動く範囲を記録する
5. 配信へ音を渡す

各手順の「この手順の画面へ」を押すと、その設定がある画面に移り、該当する場所が強調されます。手順を終えると案内に完了の印が付きますが、自動では次へ進みません。確認できたら「確認して次へ」を押してください。

途中でやめるときは「あとで（使い方から再開）」を押します。あとから「使い方」タブの「チュートリアルを始める」で最初から再開できます。

## 手順

### 1. マイクと出力先を選ぶ

「デバイス」タブを開き、「音声経路」が「通常」になっていることを確認します。「入力デバイス（マイク）」で使うマイクを、「出力デバイス」でヘッドホンをつないだ機器を選びます。分からなければ「システム既定」のままで構いません。

DAWの中で使う場合は「DAW（VSTブリッジ）」を選び、[VSTブリッジの手順](../audio/vst-bridge)へ進んでください。

![「デバイス」画面](/img/screenshots/ja/device-ja.png)

_「デバイス」画面。「通常」では、この画面でマイクと出力先を選びます。_

### 2. 「開始」を押して声を出す

上部の「開始」を押し、マイクに向かって「あー」と声を伸ばします。自分の声がヘッドホンから返り、上部の入力・出力メーターが動けば成功です。

### 3. 赤い点をドラッグして声を動かす

「位置」タブの「操作モード」を「マニュアル」にします。声を伸ばしたまま、位置パッドの赤い点（あなたの声）を掴んで左右へ動かします。ヘッドホンの中で声が動けば、VOrbit ASMRの基本の体験は完了です。

![マニュアルにした「位置」画面](/img/screenshots/ja/position-manual-ja.png)

_左のパッドは左右と上下、右のパッドは左右と奥行きを表します。赤い点が声です。_

### 4. 自動で動かす（任意）

アバターの動きに合わせて声を動かしたい場合は、[トラッキングを接続](../tracking/overview)し、[中央と可動範囲を較正](../tracking/calibration)します。

### 5. 配信へ音を渡す

配信する場合は、[OBS・配信へ音を載せる](../streaming/obs)を参照してください。

:::tip ノイズ軽減は任意です
PCファンや空調などの一定した環境ノイズが気になるときだけ有効にしてください。既定ではオフで、約10 msの遅延が加わります。詳しくは[ノイズ軽減](../audio/noise-suppression)を参照してください。
:::

## うまくいかない場合

[よくある問題](../troubleshooting/common-issues)で、音切れ、音声デバイス、トラッキング接続を確認してください。
