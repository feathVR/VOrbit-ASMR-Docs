# 最初の音を出す

インストール後、声が空間音響として聞こえるところまでを設定します。最初は横方向の動きだけを使用すると、接続状態を確認しやすくなります。

## 一枚でわかる、かんたん設定

<img src="/VOrbit-ASMR-Docs/img/quick-start-ja.svg" alt="VOrbit ASMRの音出しと自動追従を5段階で説明する、かんたん設定シート" width="1200" height="1600" />

_まず1〜3で音と位置の変化を確認します。自動追従を使う場合だけ4〜5へ進んでください。[画像を開いて拡大](/img/quick-start-ja.svg)できます。_

## 用意するもの

- 使用するマイクとヘッドホンまたはイヤホン
- 対応するアバター・トラッキングアプリ
- 正面を向いた状態のアバター

:::warning
空間音響の位置を正しく確認するため、スピーカーではなくヘッドホンまたはイヤホンの使用を推奨します。
:::

## 基本設定

1. VOrbit ASMRを起動します。
2. 「デバイス」で[音声経路](../audio/routes)を選びます。
   - **通常**：この画面でマイクと出力先を選びます。
   - **DAW（VSTブリッジ）**：DAW側で入出力を設定し、[VSTブリッジの手順](../audio/vst-bridge)を行います。
3. トラッキングソースを選び、接続します。
4. 横方向（X軸）に使用するパラメーターを選びます。
5. アバターを正面の基準位置に置き、キャリブレーションします。
6. マイクに話しながら、アバターをゆっくり左右へ動かします。

横方向の値に合わせて、声が頭の周囲を弧を描くように移動すれば、基本設定は完了です。

![初回設定のデバイス画面](/img/screenshots/ja/tutorial-0-ja-light.png)

_現行バージョンの初回設定画面。「通常」では入力と出力をこの画面で選びます。まず「システム既定」のままでも確認できます。_

:::tip ノイズ除去は任意です
PCファンや空調などの一定した環境ノイズが気になるときだけ有効にしてください。既定ではオフで、約10 msの遅延が加わります。詳しくは[ノイズ除去](../audio/noise-suppression)を参照してください。
:::

![初回設定の位置確認画面](/img/screenshots/ja/tutorial-1-ja-light.png)

_位置パッドと「オート追従」の接続欄。最初は左右の動きだけで確認します。_
