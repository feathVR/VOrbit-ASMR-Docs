# OBS・配信へ音を載せる

加工後の声を、OBSへ**1系統だけ**で渡します。「デバイス」タブの「配信に乗せる方法」にも同じ案内があります。

![OBSへの渡し方の図](/img/screenshots/ja/help-streaming-ja.png)

_「使い方」タブの「OBS・配信へ音を載せる」。方法Aと方法Bのどちらか1つを使います。_

## 方法A：アプリケーション音声キャプチャ（おすすめ）

OBSで「アプリケーション音声キャプチャ」を追加し、VOrbit ASMRを指定します。VOrbit ASMRの音だけが入り、追加のソフトは不要です。

## 方法B：音声出力キャプチャ

VOrbit ASMRでヘッドホンなどの出力先を選び、OBSで「音声出力キャプチャ」を追加して同じデバイスを選びます。そのデバイスへ流れるゲーム音や通知音なども一緒に入ります。

## 短く録画して確かめる

配信前に20秒ほど、声を左右へ動かしながら録画し、ヘッドホンで再生します。左右の変化と、音が二重になっていないことを確認してください。

:::warning 音が二重になる原因
同じ音をデスクトップ音声と個別のソースの両方で取り込んだり、加工前のマイクもOBSで直接取り込んだりすると、音が二重になります。OBSのメーターで、加工後の音が一系統だけ入っていることを確認してください。
:::

## DAWを使っている場合

音声経路を「DAW（VSTブリッジ）」にしている場合、加工後の声はDAWから出ます。DAWの加工後の音をOBSへ取り込む経路を設定してください。詳しくは[VSTブリッジを使う](../audio/vst-bridge)を参照してください。

## ダミーヘッドの画像を出す（任意）

配信画面にダミーヘッドマイクの画像を出すこともできます。「位置」タブの「配信画面にダミーヘッドマイクを表示する」を有効にし、VTube Studioまたはnizima LIVE側で位置と大きさを調整します。詳しくは[音源の動き方](../spatial/overview#dummy-head-overlay)を参照してください。
