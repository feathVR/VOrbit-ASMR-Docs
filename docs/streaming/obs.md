# OBS・配信へ音を載せる

加工後の声を、OBSへ**1系統だけ**で渡します。「デバイス」タブの「配信に乗せる方法」にも同じ案内があります。

![OBSへの渡し方の図](/img/screenshots/ja/help-streaming-ja.png)

_「使い方」タブの「OBS・配信へ音を載せる」。通常は方法AかBを使い、自分の声を聞きたくない場合は下のVB-CABLE手順を使います。取り込み方法は重ねません。_

## 方法A：アプリケーション音声キャプチャ（おすすめ）

OBSで「アプリケーション音声キャプチャ」を追加し、VOrbit ASMRを指定します。VOrbit ASMRの音だけが入り、追加のソフトは不要です。

## 方法B：音声出力キャプチャ

VOrbit ASMRでヘッドホンなどの出力先を選び、OBSで「音声出力キャプチャ」を追加して同じデバイスを選びます。そのデバイスへ流れるゲーム音や通知音なども一緒に入ります。

## 自分の声を聞かずにOBSへ送る（VB-CABLE）

上の方法で録画はできても、自分の声がヘッドホンへ返ってきてつらい場合は、[VB-Audio Virtual Cable（VB-CABLE）](https://vb-audio.com/Cable/)でVOrbit ASMRの出力先を分けられます。これは音声経路が「通常」の場合の手順です。最初の動作確認で自分の声を聞くことはできますが、配信中ずっと聞く必要はありません。

1. VB-CABLEを公式サイトから入手してインストールします。Windowsに **CABLE Input**（再生デバイス）と **CABLE Output**（録音デバイス）が現れます。
2. VOrbit ASMRを「停止」し、「デバイス」の出力先を **CABLE Input (VB-Audio Virtual Cable)** に変えてから「開始」します。入力マイクはそのままです。Windowsの通常の再生先はヘッドホンのままにします。CABLE InputをWindows全体の既定の出力先にはしません。
3. OBSで「音声入力キャプチャ」を1つ追加し、デバイスに **CABLE Output (VB-Audio Virtual Cable)** を指定します。この場合、上の方法A・BによるVOrbit ASMRの取り込みは併用しません。
4. OBSでこの入力の音声モニターをオフにします。WindowsのCABLE Outputの「このデバイスを聴く」もオフにします。どちらかをオンにすると、声がヘッドホンへ戻ることがあります。
5. OBSのメーターが声に反応することを確認し、短くテスト録画します。録画を再生すると加工後の左右の動きが聞こえ、VOrbit ASMRの動作中は自分のヘッドホンへ声が返らなければ成功です。

**CABLE InputはVOrbit ASMRから音を入れる側、CABLE OutputはOBSが音を受ける側**です。名前は逆に見えますが、この組み合わせでつながります。OBSが同じ音をデスクトップ音声や加工前のマイクからも取り込んでいないか確認してください。単にOBSのモニターをオフにするだけでは、VOrbit ASMRがヘッドホンへ直接出している音は止まりません。

## 短く録画して確かめる

配信前に20秒ほど、声を左右へ動かしながら録画し、ヘッドホンで再生します。左右の変化と、音が二重になっていないことを確認してください。

:::warning 音が二重になる原因
同じ音をデスクトップ音声と個別のソースの両方で取り込んだり、加工前のマイクもOBSで直接取り込んだりすると、音が二重になります。OBSのメーターで、加工後の音が一系統だけ入っていることを確認してください。
:::

## DAWを使っている場合

音声経路を「DAW（VSTブリッジ）」にしている場合、加工後の声はDAWから出ます。DAWの加工後の音をOBSへ取り込む経路を設定してください。詳しくは[VSTブリッジを使う](../audio/vst-bridge)を参照してください。

## ダミーヘッドの画像を出す（任意）

配信画面にダミーヘッドマイクの画像を出すこともできます。「位置」タブの「配信画面にダミーヘッドマイクを表示する」を有効にし、VTube Studioまたはnizima LIVE側で位置と大きさを調整します。詳しくは[音源の動き方](../spatial/overview#dummy-head-overlay)を参照してください。
