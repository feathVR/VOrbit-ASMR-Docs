# VSTブリッジを使う

VSTブリッジは、DAWやVSTホスト内のマイク音声をVOrbit ASMRへ送り、空間化した音声を同じプラグイン位置へ戻します。

<img src="/VOrbit-ASMR-Docs/img/vst-bridge-flow-ja.svg" alt="マイクからDAWのVOrbit Bridge、DAW出力を経てOBSへ音を渡す。VOrbit ASMRはBridgeと音声を往復し、ヘッドホンは別のモニター経路として示す図" width="1400" height="820" />

_音声の流れを示す概念図です。[画像を開いて拡大](/img/vst-bridge-flow-ja.svg)できます。_

OBSへ配信する場合は、**DAWの加工後音声をOBSに取り込む経路を別途設定**します。DAWの出力先や仮想音声デバイスなど、使う環境に合う方法を選んでください。ヘッドホンで聞こえることだけでは、OBSに届いた確認にはなりません。OBSの音声メーターと短いテスト録画で確認してください。

## 設定手順

「デバイス」タブで「DAW（VSTブリッジ）」を選ぶと、「DAW で使う（VSTブリッジ）」に4つの手順が表示されます。

1. **「VOrbit Bridge.vst3」をDAWのVST3フォルダーへコピーする**
   「ブリッジの場所を開く」を押し、開いたフォルダーの **`VOrbit Bridge.vst3` をフォルダーごと**、使用するDAWが読み込むVST3フォルダーへコピーします。名前は .vst3 ですが中身の入ったフォルダーです。中のファイルだけを取り出さないでください。
2. **VOrbit ASMRの音声経路を「DAW（VSTブリッジ）」にする**
   「開始」している間は切り替えられないので、先に「停止」してください。
3. **ホストで再スキャンし、マイクのトラックに挿す**
   DAWでプラグインを再スキャンし、マイクのトラックへ **VOrbit Bridge** を挿します。DAWの入力モニターも有効にします。
4. **「開始」を押す**
   DAWから接続されると、空間化を始められます。

![VSTブリッジの設定画面](/img/screenshots/ja/vst-bridge-ja.png)

_画面内にも、コピー元と現在の接続状態が表示されます。画像のパスは開発環境の例で、実際の場所はインストール先によって異なります。_

## DAW側の設定

- 入力デバイス、出力デバイス、サンプルレート、バッファーはDAW側で設定します。
- 対応サンプルレートは **44.1 kHz / 48 kHz** です。
- VOrbit ASMRと接続していないとき、プラグインは音声をそのまま通します。
- 素材の音とコラボ相手の声は、ブリッジを挿したトラックの出力としてDAWへ返ります。DAW全体のミックスには挿さないでください（相手の声が相手へ戻り、エコーになります）。
- DAWが接続していない間は、「音源」の再生とコラボ通話は使えません。
- 書き出し（オフライン処理）とフリーズでは、音声はそのまま通ります。

## 声・素材・通話相手を別々に録りたい場合

同じフォルダーにある **`VOrbit Bridge Multi.vst3`** も一緒にコピーし、DAWで楽器として立ち上げてください。単体では音が出ません。

## 更新・やめるとき

- VOrbit ASMRを更新したら、新しい `VOrbit Bridge.vst3` をもう一度コピーしてください。
- やめるときは、コピーした `VOrbit Bridge.vst3` を自分で削除してください。アンインストールでは消えません。

接続できない場合は、VOrbit ASMRを停止して音声経路を選び直し、DAWでプラグインを再スキャンしてください。
