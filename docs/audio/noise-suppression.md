# ノイズ軽減

「環境ノイズを控えめに軽減」は、PCファンや空調などの一定した環境ノイズを抑える任意の機能です。既定ではオフです。

## 使う目安

- 無音時にも一定のファン音や空調音が聞こえる場合はオンを試します。
- 息遣い、ささやき、細かな音の質感を優先する場合は、まずオフのまま確認します。
- 有効にすると約 **10 ms** の遅延が加わります。

この設定は動作中には変更できません。いったん「停止」して切り替えると、次に「開始」したときから反映されます。配信や録音を始める前に、ヘッドホンで声と小さな音の聞こえ方を確認してください。

:::note
ノイズ軽減はマイクから入る声に適用されます。ステレオ／バイノーラル素材の入力には適用されません。
:::
