# 音声経路を選ぶ

VOrbit ASMRは、使い方に合わせて音声の通り道を選べます。音質の優劣ではなく、普段の配信・録音環境に合う方を選んでください。「デバイス」タブの「音声経路」で切り替えます。

| 音声経路 | 向いている使い方 | 入出力の設定場所 |
| --- | --- | --- |
| **通常** | VOrbit ASMRだけで手早く使う | VOrbit ASMRの「デバイス」画面 |
| **DAW（VSTブリッジ）** | DAWのトラックや既存エフェクト構成へ組み込む | DAW／VSTホスト |

![「デバイス」画面の設定](/img/screenshots/ja/device-card-ja.png)

_「通常」のときの「デバイス」画面。音声経路、ノイズ軽減、入出力デバイス、音切れ対策、配信に乗せる方法が並びます。_

## 通常を選ぶ場合

「入力デバイス（マイク）」でマイク、「出力デバイス」でヘッドホンまたはイヤホンを選び、上部の「開始」を押します。初回確認では「システム既定」のままでも構いません。機器をつなぎ直したときは「再検出」を押します。

### 周波数をそろえる

「周波数」に、マイクと出力のサンプルレートが表示されます。両方を同じ値（対応：44100 / 48000 / 88200 / 96000 Hz）にそろえてください。周波数はWindowsのサウンド設定か、オーディオインターフェースの設定画面で変えられます。変えたら、いったん「停止」してから「開始」し直します。

### 音切れ対策モード

プツプツという音や音切れが続くときは、「音切れ対策モード」をオンにします。マイクと出力を別々に動かし、間に余裕を持たせるため、遅延が約30 ms増えます。マイクと出力が別の機器でも安定します。

## DAW（VSTブリッジ）を選ぶ場合

VOrbit ASMRは音声デバイスを直接開きません。DAWに挿した **VOrbit Bridge** から音声を受け取り、空間化した音声を同じ場所へ返します。デバイス、サンプルレート、バッファーはDAW側で設定します。

オーディオインターフェースを使っている場合は、こちらの方が安定することがあります。続けて[VSTブリッジを使う](./vst-bridge)を設定してください。

:::note
「開始」している間は、音声経路、入出力デバイス、ノイズ軽減、音切れ対策モードを変更できません。いったん「停止」してから変更してください。
:::
