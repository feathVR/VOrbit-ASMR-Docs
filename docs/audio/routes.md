# 音声経路を選ぶ

VOrbit ASMRは、使い方に合わせて音声の通り道を選べます。音質の優劣ではなく、普段の配信・録音環境に合う方を選んでください。

| 音声経路 | 向いている使い方 | 入出力の設定場所 |
| --- | --- | --- |
| **通常** | VOrbit ASMRだけで手早く使う | VOrbit ASMRの「デバイス」画面 |
| **DAW（VSTブリッジ）** | DAWのトラックや既存エフェクト構成へ組み込む | DAW／VSTホスト |

![音声経路の選択画面](/img/screenshots/ja/audio-route-ja.png)

_「通常」と「DAW（VSTブリッジ）」は、開始前に切り替えます。_

## 通常を選ぶ場合

「入力」でマイク、「出力」でヘッドホンまたはイヤホンを選び、「開始」を押します。初回確認ではシステム既定のままでも構いません。

## DAW（VSTブリッジ）を選ぶ場合

VOrbit ASMRは音声デバイスを直接開きません。DAWに挿した **VOrbit Bridge** から音声を受け取り、空間化した音声を同じ場所へ返します。デバイス、サンプルレート、バッファーはDAW側で設定します。

続けて[VSTブリッジを使う](./vst-bridge)を設定してください。

:::note
音声経路は動作中に切り替えられません。いったん「停止」してから切り替えてください。
:::
